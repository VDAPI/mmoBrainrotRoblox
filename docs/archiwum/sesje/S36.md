## D. Komponenty (kontrakt dla S37–S44)

Statyczne `.astro` w `src/components/`. Komponenty potrzebne też w wyspach (`ItemTooltip`, `ItemIcon`, `RarityBadge`) pisz w **Svelte 5** w `src/components/`: Astro renderuje je bez `client:` do czystego HTML (zero JS), a wyspy importują te same pliki. Dane podawaj przez id + `src/lib/data.ts` (typowane gettery z `types.ts`: `getItem`, `getMonster`, `getBoss`, `getMap`, `rarityOf`…) albo przez gotowy obiekt (`ItemTooltip` przyjmuje `TooltipData` z `src/lib/tooltip.ts`). Kolory rzadkości/żywiołów zawsze przez `--c: var(--vw-r-<key>)` itd., nigdy wpisane klucze.

- `SectionTitle` `{ as?: "h2"|"h3", id? }` → `.vw-section-title` + `.vw-h2`. `Label` → `.vw-label`.

## G. Wyszukiwarka (`Szukaj-desktop.jpg`, `Szukaj-mobile.jpg`)

1. **Indeks.** `scripts/search-index.mjs` używa API Node Pagefind (`createIndex`, `addDirectory({ path: "dist" })`, `addCustomRecord`, `writeFiles` do `dist/pagefind`): to odpowiednik `pagefind --site dist`, plus **rekordy z danych dla sekcji jeszcze niegotowych**, żeby wyszukiwarka działała od dziś. Rekordy liczy endpoint Astro `src/pages/wiki-records/[lang].json.ts` (nie z podkreślnikiem: Astro pomija pliki `_*` w `pages`; te same funkcje TS co strony: nazwy, meta, `tooltipData`), skrypt dokłada je do indeksu i kasuje `dist/wiki-records/`. Rekord: `url` (przyszły adres z `href`; umiejętność → strona klasy z kotwicą `#s-<skillId>`, obszar/jaskinia → `/pl/krainy/<mapa>/<id>/`), `language`, `content` (nazwa, linia meta, opis), `filters: { type }` — **klucze typów są kontraktem dla S37–S43**: `item`, `monster` (potwory i bossy), `region` (mapy, obszary, jaskinie), `quest`, `skill` (umiejętności i strony klas), `guide` (poradniki i mechaniki), `meta` (tytuł, typ, rzadkość, poziom, glif, `pending: "1"`, dla przedmiotów `tooltip` = JSON `TooltipData`). Gdy sekcja ma `ready: true`, rekordy jej typu są pomijane (indeksują się prawdziwe strony z `data-pagefind-body`). Główna, styleguide i 404 nie są indeksowane (uwaga: gdy żadna strona nie ma `data-pagefind-body`, Pagefind bierze całe strony; wyklucz je np. opcją `glob` w `addDirectory` albo `data-pagefind-ignore="all"` i sprawdź, wyszukując „Vaelthorn”).
2. **Strona `/pl/szukaj/?q=&t=`** (wyspa `src/islands/SearchPage.svelte`, `client:load`; Pagefind ładowany dynamicznie z `/pagefind/pagefind.js`; w `npm run dev` bez indeksu pokazuje komunikat „pełne wyszukiwanie po `npm run build && npm run preview`”).
