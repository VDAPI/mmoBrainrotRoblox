### B. Importer: `tools/icons/import_items.py`

**B1. Wspólna biblioteka `tools/icons/artlib.py` (plan).** Czyste funkcje bez stanu globalnego, użyje ich też S119 (atlasy interfejsu). Tylko Pillow i biblioteka standardowa.
- `graphics_root(cli_arg)`: `--src` → `VAELTHORN_GRAPHICS` → `D:\Users\vdapi\Downloads\Graphics`; zwraca `None`, gdy katalogu nie ma.
- `load_rgba(path)`: otwiera PNG (także paletowy i z `tRNS`), konwertuje do RGBA; nie-PNG pomija z ostrzeżeniem.
- `transparency(img)`: rozpoznaje tło: (a) jest prawdziwa alfa (co najmniej 2% pikseli z alfą < 250) → OK; (b) brak alfy, a ≥ 90% pikseli brzegu (pas 2% szerokości) jest blisko magenty `#FF00FF` (odległość ≤ 60) → wycięcie magenty z miękką krawędzią (alfa liniowo w odległości 60–120, odbarwienie fioletowej obwódki); (c) brzeg to szachownica dwóch szarości (udawana przezroczystość z ChatGPT) albo jednolity kolor → **odrzucenie** z powodem „brak przezroczystości (szachownica | jednolite tło)”; flaga `--key auto` (domyślnie wyłączona) wycina wtedy tło zalewaniem od brzegu z tolerancją 24 i dopisuje ostrzeżenie do raportu.
- `fit_icon(img, cell, margin=0.06)`: obcina do ramki alfy (alfa > 8), dopełnia do kwadratu przezroczystością (środek), dodaje margines 6% boku, zmniejsza do `cell` (Lanczos), lekkie wyostrzenie (`UnsharpMask(radius=0.8, percent=60, threshold=2)`), alfa poniżej 3 zerowana. Bok źródła < 256 → odrzucenie („za mały”). Wynik zawsze `cell × cell` RGBA.
- `fit_tile(img, cell)` (dla S119: kafelek na cały kwadrat, bez obcinania do alfy) i `fit_box(img, w, h)` (obrazy pojedyncze) mogą powstać od razu albo w S119.
- `pixel_hash(img)`: `sha1` surowych bajtów RGBA, pierwsze 10 znaków hex (nie bajtów pliku: ten sam obraz zapisany inaczej nie wymusza ponownego wgrania).
- `Packer(sheet_size=1024, cell=128)` ze **stałymi komórkami**: `load(index)` (dotychczasowy przydział `key → (sheet, x, y, hash)`), `place(key, img)` (klucz znany → ta sama komórka, nadpisana tylko przy innym hashu i wtedy arkusz oznaczony jako zmieniony; klucz nowy → pierwsza wolna komórka **ostatniego** arkusza, a gdy pełny, nowy arkusz), `alias(key, of_key)` (ta sama komórka pod drugim kluczem, np. pięć rzadkości błogosławieństwa), `drop(key)` (tylko z `--prune`: zwalnia komórkę i czyści ją do przezroczystości), `save(dir, name_fmt)` (zapis tylko zmienionych i nowych arkuszy, PNG bez metadanych, `optimize=False`, ten sam wynik bajt w bajt), `changed_sheets()`, `sheet_hash(n)`.
- `write_luau(path, header, body)` i `run_stylua(path)` (jeśli `stylua` jest w PATH; inaczej przypomnienie w wydruku).
- `read_ids_dump(path | None)`: uruchamia `lune run tools/icons/ids.luau` (A2), gdy nie dostał pliku; bez Lune i bez `--ids` kończy się błędem z instrukcją (walidacja nazw jest obowiązkowa).

### C. Gra

**C1. Indeks i id.** `Data/ItemArtAtlas.luau` (B4) i `Data/ItemArtSheets.luau` (D4) w repo od pierwszego przebiegu (także pustego). `art/` leży poza drzewem Rojo (jak S35).

**C2. `Logic/ItemIcons.luau`** (czysty; zmiany wsteczne zgodne):

- `ItemIcons.resolve(def, element?, opts?)` z `opts: { art: ((sheet: number) -> boolean)?, layered: boolean? }`: najpierw własna ikona, gdy jest w indeksie i `opts.art(s)` jest prawdą (domyślnie: atlas ma id `rbxassetid://<cyfry>`); wynik `{ key = "art/<id>", layers = { { image = ART_FIRST + s - 1, x, y } }, art = true }` (bez `tint`: ikony z PNG mają własne kolory). - `ItemIcons.artReadyFor(ids, s)` (czysta, testowalna) i `ItemIcons.coverage(): { items = n, withArt = n, byGroup = { … } }` dla `/icons`.

**C3. `UI/IconState.luau` per atlas.** Dochodzą `IconState.ArtOk` (`Value<{ [number]: boolean }>`, atlas własnych ikon wczytany) i `IconState.ArtStatus` (`{ [number]: string }`); `load()` wczytuje atlasy S35 jak dziś, a atlasy z `ItemArtSheets` **osobno** (te same instancje `ImageLabel`, jedno `PreloadAsync` dla wszystkich z id), z jednym ostrzeżeniem `[ItemIcons] art sheet N: <status>` na atlas, który się nie wczytał. Atlas bez id: cicho `none`. Nowa funkcja `IconState.picture(use, def, element?): Resolved?`, jedyne miejsce decyzji w kliencie: `Mode == "glyph"` → nil; potem `ItemIcons.resolve(def, element, { art = function(s) return use(IconState.ArtOk)[s] == true end, layered = use(IconState.Ok) })`. Analogicznie `IconState.questPicture(use, item)`. Zasada „nigdy pół na pół” S35 zmienia się na „**nigdy pół ikony**”: jeden przedmiot jest w całości z PNG, w całości z warstw S35 albo glifem, ale różne przedmioty mogą być w różnym stanie (zapisz w DECYZJE i w DESIGN §5.3b).

Gdy `resolved.art` i jest `Element` (broń maga), dochodzi mały **klejnot żywiołu**: okrąg 28% rozmiaru w prawym dolnym rogu ikony, kolor `Elements.COLORS[element]`, cienka ciemna obwódka, `ZIndex` nad warstwami (ikona z PNG ma stałe kolory, więc żywioł trzeba pokazać inaczej niż akcentem S35).
