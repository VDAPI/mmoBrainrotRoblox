### B. Logika `src/shared/Logic/Achievements.luau` (czysta)

1. `Achievements.state(account, character) -> { acc, chr }` z ochroną typów (śmieci → puste tablice, ujemne / NaN → 0).
2. `Achievements.apply(st, counter, mode, value, key?) -> { newly: { string } }`: `add` (+value), `max` (max), `set` (dodaje `key` do zbioru); zwraca osiągnięcia z `byCounter[counter]`, które **właśnie** przekroczyły `goal` (nie były w `done`), w kolejności `goal`. Nie wpisuje `done` (robi to serwer razem z nagrodą — jedna ścieżka).
3. `Achievements.progress(st, def) -> (value, goal)` (dla okna S151b i testów); dla `set` z celem „wszystkie X” `goal` liczony z danych (`Data/Maps`, `Data/Areas.lairs`, `Data/Bosses` bez `world`), więc nowa mapa / kryjówka podnosi cel sama (linia w DECYZJE: zdobyte zostaje zdobyte).
4. `Achievements.reward(def, paid) -> { title?, cosmetic?, shards (0, gdy `paid[def.id]`), gold }` — jedna wypłata odłamków na konto.
5. **Zdarzenia → liczniki** `Achievements.COUNTER_EVENTS: { [kind]: (data) -> { { counter, mode, value, key? } } }` (czyste mapowanie z `QuestEvents`): `kill` → `kills` (+1), `eliteKills` (gdy `variant == "elite"`), `elite2Kills` (gdy `"elite2"`), `lairs` (`set`, `key = data.lair`, gdy zabita Elita II pochodzi z kryjówki — dopisz pole `lair` do danych `kill`, B6); `boss` → `bosses` (`set`, `key = bossId`), `bossKills`, `fullParty` (gdy `data.party == 5`); `worldboss` → `worldBoss`, `bosses` (`set`, `key = "hrimvald"`); `event` → `invasions` (gdy `kind == "invasion"` i `success`); `bloodmoon` → `bloodMoon`; `duel` → `duelsWon` (gdy `won`); `arena` → `arenaWins` (gdy `won`); `pvpkill` → `pvpKills`; `upgrade` → `upgraded7` (gdy `to >= 7`), `upgraded9` (gdy `to >= 9`); `craft` → `crafted`; `dismantle` → `dismantled` (+`n`); `reroll` → `rerolled`; `brew` → `brewed`; `gather` → `gathered` (+`n`); `fish` → `fish`; `trade` → `trades`; `mail` → `mailSent`; `visit` → `maps` / `caves` (`set`, `key = mapId`, wg `Data/Maps.biome`); `level` → `level` (max); `quest` → `mainDone` / `sideDone` / `contracts`; `dodge` → `dodged` (+n); `social` → `friends` (max), `guild` (max).
6. **Zaliczenie dawnych postępów** `Achievements.backfill(account, character) -> { { counter, mode, value, key? } }` (czyste, idempotentne; serwer stosuje przez `apply` jak każde zdarzenie): `level`, `mainDone`, `sideDone` (liczba `quests.side.done`), `contracts` (`quests.contract.done`), `pvpKills` (`pvp.kills`), `duelsWon` (`pvp.duelsWon`), `arenaWins` (`arena.wins + arena.wins3` bieżącego sezonu, max z `last` — dolna granica), `maps` / `caves` (`visitedMaps`), `bosses` (`set`: boss, którego quest fabuły jest ukończony — `Main.indexOf[bossQuest] <= mainDone`; dolna granica), `bossKills` (max z liczbą elementów `bosses`), `worldBoss` (1, gdy `account.worldBoss.last` istnieje), `friends` (liczba `account.social.friends`), `guild` (1, gdy `guildId`), `earnedCosmetics` (liczba posiadanych z `obtain`), `tourney`, jeśli dodasz licznik. Reszta liczy się od tej sesji (lista w DESIGN §20b i na wiki S151b: „liczone od wprowadzenia osiągnięć”).
7. `Achievements.shardTotal() -> number` i `Achievements.shardsBy(level)` (do SESJE / DESIGN: ile odłamków może mieć gracz po zaliczeniu dawnych postępów na poziomie L — przybliżenie z liczników `backfill` dla typowej postaci).

### C. Serwis `src/server/Services/AchievementService.luau`
