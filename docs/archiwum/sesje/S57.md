**B3. Wartości węzłów, odwołania i osłabienie poza ścieżką główną (konwencja dla sesji klas).**
- Liczby zależne od rangi węzła leżą w `node.values` (`{ ranga 1, ranga max }`). `passive`, `aura` i `luck` mapują statystykę albo pole na **nazwę pola** `node.values` (jak `skill.passive`).
- W `modify.bp` każda liczba zależna od rangi to `{ ref = "<pole node.values>" }`, w dowolnym miejscu (także zagnieżdżona). `skillMods` podmienia ją na wartość na randze węzła × `scale`; wewnątrz `mul` na `1 + (x − 1) × scale`. Liczby wpisane wprost (np. stały promień) nie zależą od rangi ani od `scale`.
- Efekty przełomów czytają liczby z pól umiejętności po nazwie, więc liczbę węzła dla efektu podajesz przez `bp.values.<nowePole> = { ref = "…" }`, a efekt wskazuje `"<nowePole>"` (wzór: `armorBp` z S55).
- `scale` węzła: 1, chyba że rząd ≤ `DIP_ROWS`, ścieżka nie jest główną (także gdy głównej jeszcze nie ma) i węzeł jest drużynowy; wtedy `node.dipScale or DIP_SCALE`. Węzeł drużynowy (`Paths.isTeamNode(node)`): rodzaj `aura`; albo `modify.bp`, w którym którykolwiek efekt (`effect`, `selfEffect`, `allyEffect` i listy `effects` / `allyEffects` / `selfEffects`, jeśli są) ma `not EffectStack.isOwn(effect.category)`; albo jawne `dipScale` (tak oznaczasz drużynowy hak w `passive`). Rodzaj `luck` nigdy (6.3). `allyEffect` **bez** kategorii (leczenie, tarcza, nietykalność) nie czyni węzła drużynowym (ROZWOJ 2.2: liczy się kategoria inna niż `own`; S71 zakłada, że takie efekty w rzędach 1–2 działają w pełni). Ta sama `scale` trafia do `ActiveNode.scale`, z której korzystają S60 i S61.

**B4. Reguła broni (`weaponOk`, łatwo odwrócić, test w obie strony).** Typy dwuręczne licz raz przy ładowaniu modułu z `Data/Items/Bases` (`base.weapon and base.weapon(1).twoHanded`).

```lua
function weaponOk(req, weapons)
	if req == nil then return true end
	if req.main and (weapons.main == nil or table.find(req.main, weapons.main) == nil) then return false end
	if req.offhand == nil then return true end
	if req.main and TWO_HANDED[weapons.main] then return true end -- a listed two-hander needs no off-hand
	return weapons.offhand ~= nil and table.find(req.offhand, weapons.offhand) ~= nil
end
```

Przykłady z 2.8: Niszczyciel (`main = { "staff", "wand" }, offhand = { "orb" }`): sam kostur tak, różdżka z kulą tak, sama różdżka nie, kostur runiczny nie. Kapłan Fortuny (`offhand = { "relic" }`, `main = nil`): buława z relikwią tak, kostur kapłański (dwuręczny, bez drugiej ręki) nie.
