## Kontekst

Właściciel chce rozwinąć każdą profesję w wielu kierunkach, a Kapłan ma być prawdziwym wsparciem (prośba na końcu pliku). ROZWOJ zamienia to na trzy ścieżki Kapłana, a pierwszy krok to leczenie, które zostaje w 25–35% HP tanka na każdym poziomie (cel T-SK5, ROZWOJ 0 i 7.5): dziś Leczenie rośnie tylko z ataku magicznego i na 70. poziomie leczy Wojownika o ok. 83% jego HP jednym rzutem. ROZWOJ 7.5: „Leczenie i tarcze od maks. HP celu plus mała część ataku magicznego (`values.healHp`, `values.healMag`, `Skills/Context.heal`)”. ROZWOJ 2.7: każda aktywna dostaje na 5. i 10. randze wybór A (dzisiejszy przełom) albo B (nowy); bez wyboru działa A. ROZWOJ 2.6 pozwala, żeby opcje B działały, zanim klasa ma ścieżki.

Krytyka planu sesji przestawiła kolejność w klasie względem ROZWOJ 13.7 („sesja 1 dane, sesja 2 nowe zachowania, sesja 3 haki i teksty EN”): zachowanie wchodzi w tej samej sesji co dane, które go używają, bo inaczej opcje B czytałyby `shieldHp`, którego jeszcze nie ma. Ta sesja to zapisuje (I1, I2).

### A. `Logic/Skills`: kwota leczenia i tarczy, pola krzywej, kolejność łańcucha

1. **`Skills.healAmount`** (czysta, w `src/shared/Logic/Skills.luau`, obok `healMul` z S54). Jedyny wzór kwoty leczenia i tarczy dla serwera (`ctx.healAmount`), podpowiedzi (`SkillInfo.healLine`) i testów:

   ```lua
   -- S69 (ROZWOJ 7.5, 9.2): base heal or shield of `def` (already Skills.effective) at `rank` on a target with
   -- `targetMaxHp`, before heal bonuses, item power and PvP scaling. prefix "heal" reads values.healHp / healMag,
   -- "shield" reads values.shieldHp / shieldMag. Only the magic-attack part follows the heal curve (S54).
   -- Data without the Hp / Mag pair keeps the formula from before S69: magic attack x curve x values[prefix] %.
   function Skills.healAmount(
   	def: SkillDef,
   	rank: number,
   	prefix: "heal" | "shield",
   	targetMaxHp: number,
   	magAtk: number,
   	level: number
   ): number
   	local hpField, magField = def.values[prefix .. "Hp"], def.values[prefix .. "Mag"]
   	local curve = Skills.healMul(level)
   	if hpField == nil and magField == nil then
   		return magAtk * curve * Skills.valueAt(def, prefix, rank) / 100
   	end
   	return targetMaxHp * Skills.scaled(def, hpField, rank) / 100 + magAtk * curve * Skills.scaled(def, magField, rank) / 100
   end
   ```

   `Skills.scaled(def, nil, rank)` daje 0, więc gdy w danych jest tylko jedno z pary, drugie liczy się jako 0. `level` to poziom postaci **rzucającego** (krzywa z S54), `rank` to ranga umiejętności. Nie zaokrąglaj (serwer, podpowiedź i test porównują tę samą liczbę).
2. **`Skills.healFields(skill)`** (S54): pola mnożone krzywą w `descriptionArgs`. Nowa reguła na początku funkcji: gdy `skill.values.healMag ~= nil` → `{ "healMag" }`; gdy `skill.values.shieldMag ~= nil` → `{ "shieldMag" }`; w przeciwnym razie dotychczasowa reguła S54 (Światłość `{ "heal" }`, pozostałe typy leczenia `{ "heal" }` / `{ "shield" }`, Pobożność, Boska Interwencja i Święte Uderzenie `{}`). `healHp` / `shieldHp` nigdy nie idą przez krzywą. Zaktualizuj komentarz funkcji. Opis Leczenia na L ≤ 20 pokazuje więc dokładnie wartości z danych (krzywa = 1), a od S87 część „% ataku magicznego” rośnie z krzywą.
3. **Łańcuch leczenia** (czyste, w tym samym pliku; test w „Testach”):

   ```lua
   -- S69 (ROZWOJ 9.2, Heal 10B chainHeal): order of the next chain targets. `fractions[i]` is the HP share of
   -- candidate i (already without the targets healed in this cast). Only wounded candidates (< 1), the most
   -- wounded first, ties by lower index, at most `jumps`. Returns candidate indices.

   -- Share of the k-th jump (k = 1, 2, ...): (pct / 100) ^ k, e.g. 60 -> 0.6, 0.36.

   ```

   -- S69 (Heal 10B): the heal jumps to more wounded allies in range, each once per cast.
   local function chainHeal(ctx: Ctx, chain: { jumps: number, pct: number }, healed: { [Player]: boolean })
   	local range = (ctx.skill :: any).range or 30
   	local pool: { Player }, fractions: { number } = {}, {}
   	for _, ally in ctx.alliesInCircle(ctx.root.Position, range + RANGE_TOLERANCE) do
   		if not healed[ally] then
   			local maxHp = ctx.services.Stat.GetValue(ally, "maxHp")
   			table.insert(pool, ally)
   			table.insert(fractions, if maxHp > 0 then ctx.services.Resource.Get(ally) / maxHp else 1)
   		end
   	end

   		local ally = pool[index]
   		local entity = ctx.services.Entity.GetPlayerEntity(ally)

   			ctx.fx({ t = entity.id, n = k + 1 })
   			healOne(ctx, ally, entity, ctx.healAmount(ally, "heal") * Skills.chainShare(chain.pct, k))
   		end
   	end
   end
