### B. Czysta logika

1. **`src/shared/Logic/Traits.luau`** (S63, S64), dopisz pod istniejącymi funkcjami (wymaga już `Data/Combat`; dopisz `require` `Data/Stats` dla limitu wampiryzmu i `Formula.unarmed.speed`):
   ```lua
   export type Spot = { x: number, z: number }
   export type Seal = { x: number, z: number, since: number, lit: boolean }
   export type ElementSpec = {
   	burnPct: number, burnDuration: number, exactTicks: boolean?, -- exactTicks: Traits.dotTick (items); nil: hit x pct / duration (skills, as before S65)
   	slowPct: number, slowDuration: number,

   export type ElementPlan = {
   	kind: "burn" | "slow" | "arc",
   	pct: number, -- burn: % of the hit in total; slow: slow %; arc: % of the hit for the jump
   	duration: number, -- burn / slow seconds (0 for arcs)
   	tick: number?, -- burn: damage per tick
   ```

   - `Traits.elementPlan(element: string?, spec: ElementSpec, hit: number, rider: number, dotBonus: number, staffArc: boolean): ElementPlan?` (`r = max(0, rider)`):
     - `"fire"`: `pct = burnPct × (1 + r / 100)`, `duration = burnDuration`, `tick = if spec.exactTicks then Traits.dotTick(hit, pct, burnDuration, dotBonus) else max(1, hit × pct / 100 / burnDuration) × (1 + dotBonus / 100)`;
     - `"ice"`: `pct = slowPct` (wartość bez zmian: spowolnienia z przedmiotów najwyżej 20%, umiejętności 25%, STATY 5), `duration = slowDuration × (1 + r / 100)`;

     Przy `r = 0` i `spec = SkillData.ADAPTIVE` wynik to **dokładnie** dzisiejszy `adaptiveEffect` (test).
2. **`src/shared/Logic/EffectStack.luau`** (S53, S63), dopisz (ROZWOJ 7.2, STATY 5 „Stosy”):
   ```lua
   export type Running = { tickAmount: number, nextTick: number, expiresAt: number }
   export type AccumulateSpec = { total: number, limit: number?, duration: number, now: number, interval: number }

   -- Ticks a schedule still deals: at nextTick, nextTick + interval, ... while < expiresAt (tickEntity removes
   -- the effect before a tick that falls on expiresAt).
   function EffectStack.ticksBetween(nextTick: number, expiresAt: number, interval: number): number
   	return math.max(0, math.ceil((expiresAt - nextTick) / interval - 1e-9))
   end

   -- S65 (ROZWOJ 7.2): refreshing a running DoT adds the unpaid rest to the new total; nextTick does not move.
   -- `limit`: the pending sum is at most limit x total (3 sums of one hit for item bleeds and poisons).
   -- Returns the new tickAmount and nextTick.
   function EffectStack.accumulate(old: Running?, spec: AccumulateSpec): (number, number)
   ```
   Bez `old` (albo `old.expiresAt ≤ now`): `nextTick = now + interval`, `tick = total / max(1, ticksBetween(nextTick, now + duration, interval))`. Z `old`: `unpaid = old.tickAmount × ticksBetween(old.nextTick, old.expiresAt, interval)`, `pending = unpaid + total`, przy `limit` `pending = min(pending, limit × total)`, `nextTick = old.nextTick` (także zaległy, którego pętla jeszcze nie zadała: należy do `unpaid`), `tick = pending / max(1, ticksBetween(nextTick, now + duration, interval))`.
