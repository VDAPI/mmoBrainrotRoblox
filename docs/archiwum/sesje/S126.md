### B. Czysta logika (`src/shared/Logic/Elo.luau`, `src/shared/Logic/ArenaRules.luau`; nowe)

**B1. `Logic/Elo.luau`** (ok. 60 linii, liczby z `Data/Arena.ELO`):
- `Elo.expected(r: number, opp: number): number` = `1 / (1 + 10 ^ ((opp − r) / scale))`;
- `Elo.k(played: number): number` = `kNew`, gdy `played < newGames`, inaczej `k`;
- `Elo.delta(r: number, opp: number, score: number, k: number): number` = `math.floor(k × (score − expected) + 0.5)` (zaokrąglenie do całości, symetryczne dla wygranej i przegranej przy równych ratingach);
- `Elo.apply(r: number, delta: number): number` = `math.max(floor, r + delta)`;
- `Elo.sideRating(ratings: { number }): number` = średnia zaokrąglona (dla 1v1 to ten jeden rating; S128 użyje jej dla drużyny bez zmiany wzoru).

**B2. `Logic/ArenaRules.luau`** (ok. 380 linii; wszystkie typy wymiany są tu, bo S127 przesyła je przez MemoryStore i `TeleportData`, więc **nie zawierają instancji Roblox**):

export type Pairing = { mode: string, bracket: string, sides: { { Ticket } } }
export type MatchSpec = {

	unrated: { [string]: boolean }, -- entrant keys whose rating this match will not change (same opponent > 3 today)

- `tierOf(rating): string`, `tierProgress(rating): (string?, number)` (następny próg i ile brakuje; Mistrz → `nil, 0`).

- `pair(tickets: { Ticket }, now: number, teamSize: number?): ({ Pairing }, { Ticket })` — dobór deterministyczny: bilety posortowane po `joinedAt` (remis: `entrant.key`), dla najstarszego niesparowanego biletu kandydaci z tym samym `mode` i `bracket`, innym `userId`, z `|ra − rb| <= max(window(i), window(j))`; wybór kandydata o najmniejszej różnicy ratingu (remis: starszy). Zwraca pary (strony po jednym bilecie, `sides[1]` = starszy) i resztę w kolejności. - `rollSeason(state: ArenaState, season: string): (ArenaState, ArenaSeasonSummary?)` — gdy `state.season == season`: kopia bez zmian, `nil`. Gdy `state.season == ""`: tylko ustawia sezon, `nil`. Inaczej: `last = { season = state.season, rating, peak, wins, losses, played, rewarded = false }` (**tylko gdy `played > 0`**; bez meczów w sezonie `last` zostaje poprzednie), `rating = Elo.apply(start + (rating − start) × keep)` zaokrąglone, `peak = rating`, `wins = losses = played = 0`, `season = season`. `tokens`, `daily`, `vs`, `history` bez zmian. Wynik to nowa tabela (wejście nietknięte).
- `vsCount(state, oppKey, day): number` i `isRated(state, oppKey, day): boolean` (`vsCount < LIMITS.sameOpponentDaily`).
- `roundOutcome(sides: { { Fighter } }, timedOut: boolean, tieBreak): RoundOutcome` — strona, której wszyscy mają `down` albo `left`, przegrywa (`reason = "ko"` / `"left"`); obie naraz → remis; przy `timedOut`: wyższa suma `hpPct` (dla `down`/`left` 0) wygrywa (`reason = "time"`), równość z dokładnością 0,001 → `draw = true`. Ta sama funkcja dla 1v1 i 3v3 (`tieBreak` `"hpPct"` przy jednym zawodniku daje to samo co suma; parametr zostaje dla czytelności i S128).
- `matchOutcome(score: { number }, roundsPlayed: number, mode: Mode, forfeitSide: number?): MatchResult?` — `forfeitSide` → wygrywa druga strona (`reason = "forfeit"`); ktoś ma `winsNeeded` → wygrywa; `roundsPlayed >= maxRounds` → więcej wygranych rund wygrywa, równo → remis (`reason = "draw"`); inaczej `nil` (gramy dalej).
- `applyResult(state: ArenaState, input): (ArenaState, { delta: number, rated: boolean })` z `input = { mode: Mode, season, day, now, myKey, oppKeys: { string }, oppRating, oppName, oppClass, score (1 / 0,5 / 0), rounds: string, rated: boolean }`:
  1. `rollSeason(state, season)` (mecz, który skończył się po północy na przełomie miesiąca, liczy się już do nowego sezonu);
  2. `daily`: nowy dzień → `{ day, n = 0 }`, potem `n += 1`; `vs`: nowy dzień → `{ day = day }`; liczony **przed** dopisaniem: mecz jest „z ratingiem”, gdy `input.rated` i dla każdego `oppKey` `vsCount < sameOpponentDaily`; potem `vs[oppKey] += 1`;
  3. mecz z ratingiem: `k = Elo.k(played)`, `delta = Elo.delta(rating(mode), oppRating, score, k)`, `rating = Elo.apply(...)`, `played += 1`, `wins` / `losses` (remis: żadne), `peak = max(peak, rating)`; pole ratingu wg `mode.ratingField`;
  4. mecz bez ratingu: rating, `played`, `wins`, `losses`, `peak` bez zmian (H2);
  5. `history`: nowy wpis na początek, przycięte do `LIMITS.history`.
  Wejście nietknięte, wynik to nowa tabela. **Funkcja nie dostaje nic z konta, sprzętu ani zakupów** (bez pay2win, F2).
- Geometria miejsc: `inside(venue, x, z, margin?): boolean` (kwadrat piasku, współrzędne względem mapy), `spot(venue, side, index): (number, number)` (punkt startu), `standSpot(venue, i): (number, number)`.

### G. Admin `/arena`

`cmd("combat", "arena", { enum("action", { "info", "rating", "reset", "season", "queue", "match", "stop" }), str("value", true) }, { dangerActions = { "reset" } })` (sprawdź, czy `dangerActions` działa tak, jak zakładam; wzór innych komend), `commands.arena` w `src/server/Admin/Combat.luau`:

- `season`: symuluje nowy sezon: ustawia `state.season = prevSeason(seasonOf(now))` i od razu woła ścieżkę `rollSeason` z `SeasonClosed` (do sprawdzenia `last` i miękkiego resetu bez czekania miesiąca; `/time` admina też działa, bo sezon liczy się z `Clock.now()`);
