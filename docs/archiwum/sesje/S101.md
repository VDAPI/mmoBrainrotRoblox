```lua
--!strict
-- World events (S101, docs/DESIGN-15.md §4): one event per server about every hour in an open region with players.
-- Logic/WorldEvents picks the region, the hunting ground and the scale; WorldEventService runs it.

export type KindId = "invasion" | "champion"
export type KindDef = {
	id: KindId,
	nameKey: string, -- "event.invasion.name"
	descKey: string, -- one sentence for the HUD tooltip and the wiki
	glyph: string, -- map / minimap marker
	color: string, -- hex
	weight: number, -- chance to be picked among the kinds
	duration: number, -- seconds from the start to the hard end
}

return table.freeze({
	schedule = table.freeze({
		interval = 3600, -- seconds between two starts (end -> next start counts from the planned start)
		jitter = 600, -- ± seconds, uniform
		first = table.freeze({ 900, 2100 }), -- first event after server start: 15-35 min
		warn = 120, -- announcement before the start (DESIGN-15 §4: 2 min)
		retry = 120, -- no player in an open region: try again after this
	}),
	regions = table.freeze({ "meadows", "duskwood", "ashen", "frostpeak" }), -- open region maps (Data/Maps ids)
	levelWindow = 2, -- hunting ground fits when median level is in [lv.min - window, lv.max + window]
	kinds = table.freeze({
		invasion = table.freeze({
			id = "invasion", nameKey = "event.invasion.name", descKey = "event.invasion.desc",
			glyph = "⚔", color = "#E0564A", weight = 1, duration = 720,
			waves = 6, waveEvery = 80, minWaveGap = 40, clearShare = 0.8, -- next wave early at 80 % killed
			wave = table.freeze({ base = 4, perPlayer = 2, max = 16, cluster = 4 }), -- monsters per wave, per spawn point
			eliteWaves = table.freeze({ 3, 6 }), -- these waves add one Elite
			commanderAt = 480, -- the commander comes after the last wave or at this second
			radius = 160, -- studs around the ground's centre: participants, heal / shield counting, HUD
			leash = 120,
		}),
		champion = table.freeze({
			id = "champion", nameKey = "event.champion.name", descKey = "event.champion.desc",
			glyph = "♛", color = "#E8C25A", weight = 1, duration = 900,
			routePoints = 8, pause = 8, -- waypoints, seconds of rest on each
			radius = 120, leash = 100,
			nearbyAreas = 3, -- the route crosses up to this many fitting grounds of the region
		}),
	}),
	-- Stat multipliers of the Elite II (commander / champion) by the number of players near it when it spawns
	-- (index = players, the last entry for more). Elite II of a cave is for 2-3 players (S32): one player gets less.
	scale = table.freeze({
		commander = table.freeze({ hp = { 0.45, 0.7, 1.0, 1.2, 1.4 }, atk = { 0.85, 0.95, 1, 1, 1 } }),
		champion = table.freeze({ hp = { 0.7, 1.1, 1.5, 1.9, 2.3 }, atk = { 0.9, 1, 1, 1.05, 1.1 } }),
	}),
	share = table.freeze({
		min = 0.03, -- 3 % of all points of the event ...
		hpEquivalent = 3, -- ... or 3 x the HP of a normal monster of the event level, whichever is lower
		healMul = 1, shieldMul = 1, interceptMul = 1, -- points per HP healed / absorbed / taken for an ally
		maxLevelAbove = 10, -- characters more than this above the event level help but get no event reward
	}),
	reward = table.freeze({
		expKills = 8, -- EXP = expKills x Exp.monsterExp(level, "normal"); tuned in S101 F2 (<= 3 % rule)
		goldKills = 12, -- gold = goldKills x MonsterStats.gold(level, "normal", 0.5)
		failMul = 0.5, -- time ran out: half EXP and gold, no chest
		-- Same shape as Data/LoginReward.chest (S100): rarity weights, class bias, bound to the character.
		chest = table.freeze({
			rarity = table.freeze({ [2] = 80, [3] = 20 }), -- Rarities.UNIQUE / HEROIC; never above Heroic
			classBias = 0.8, -- share of items usable by the character's class (Loot.pickItem)
			bound = true, -- like the S100 chest: no alt-account farming for the market
		}),
	}),
})
```

### B. Czysta logika: `src/shared/Logic/WorldEvents.luau` (nowy, ok. 250 linii)

Wymaga `Data/WorldEvents`, `Data/Areas`, `Data/Monsters`, `Data/Spawns`, `Data/LootTables`, `Logic/AreaAdvice`, `Logic/Exp`, `Logic/MonsterStats`, `Logic/Loot`, `Logic/ItemRoll`, `Logic/Rng`. Bez API Roblox. Każda funkcja z losowością przyjmuje `rng: Rng.Rng`.

**B1. Harmonogram.**
- `WorldEvents.firstStart(now: number, rng): number` = `now + rng:float(first[1], first[2])`.
- `WorldEvents.nextStart(plannedStart: number, rng): number` = `plannedStart + interval + rng:float(-jitter, jitter)`. Następne wydarzenie liczy się od **planowanego** startu poprzedniego, więc średnio jedno na godzinę niezależnie od długości wydarzenia; gdy wynik wypada przed końcem bieżącego wydarzenia + 5 min, przesuń go na koniec + 5 min (funkcja dostaje `notBefore: number?`).
- `WorldEvents.retryAt(now): number` = `now + retry`.

**B2. Wybór regionu, łowiska i rodzaju.**
- `WorldEvents.pickRegion(counts: { [string]: number }, rng): string?`: tylko mapy z `regions`, waga = liczba graczy (> 0), `nil`, gdy nikogo. Kolejność losowania deterministyczna: iteruj po `regions` (nie po `pairs(counts)`), losuj `rng:next() × suma`.
- `WorldEvents.medianLevel(levels: { number }): number`: mediana (przy parzystej liczbie niższa ze środkowych, żeby nie przeskalować w górę); pusta lista → 1.
- `WorldEvents.hostKinds(area): { string }`: rodzaje z `area.kinds`, które mogą być dowódcą / czempionem: istnieją w `Data/Monsters`, `passive == false`, `elites ~= false`, mają `ability`. Kolejność jak w `area.kinds`.
- `WorldEvents.canHost(area): boolean` = `#hostKinds(area) > 0` i łowisko ma co najmniej 2 spawnery w `Spawns.byMap[map]` z `areaId == area.id` (miejsca fal i punkty trasy).
- `WorldEvents.pickArea(mapId: string, level: number, rng, exclude: string?): Area?`: kandydaci to łowiska mapy z `canHost`, których `lv` z marginesem `levelWindow` obejmuje `level` (`lv[1] - w <= level <= lv[2] + w`), bez `exclude` (ostatnie łowisko wydarzenia na tym serwerze), o ile zostaje inny kandydat; równe szanse. Brak kandydata → łowisko z `canHost` o środku `lv` najbliższym `level` (remis: pierwsze w kolejności danych); na mapie bez żadnego `canHost` → `nil`. Gracze poniżej pierwszego łowiska regionu (np. 15. poziom w Duskwood) dostają wtedy najniższe łowisko, gracze powyżej najwyższe.
- `WorldEvents.pickKind(rng): KindId`: wagi `weight` po `order`.
- `WorldEvents.eventLevel(area, level): number` = `math.clamp(level, area.lv[1], area.lv[2])`: poziom wydarzenia (nagroda, poziom fal, poziom dowódcy przed `levelAdd` Elity II).

**B3. Punkty i trasa.**
- `WorldEvents.spawnPoints(mapId, areaId): { { x: number, z: number } }`: pozycje spawnerów łowiska z `Spawns.byMap` (względem `map.offset`, jak w danych), posortowane po `id` spawnera (deterministycznie).
- `WorldEvents.centre(mapId, area): { x, z }`: punkt z `spawnPoints` najbliższy `AreaAdvice.centre(area)` (stoi na pewno na dobrym terenie; sam środek prostokąta może wypaść w jeziorze albo na drodze).
- `WorldEvents.route(mapId, area, level, rng): { { x, z } }`: punkty spawnerów łowiska wydarzenia i do `nearbyAreas - 1` innych łowisk tej mapy, które pasują do `level` (te same warunki co w `pickArea`), najbliższych środkiem; z nich `routePoints` punktów: start w `centre`, potem kolejno najbliższy nieodwiedzony (najbliższy sąsiad), przy remisie mniejszy indeks. Mniej punktów niż `routePoints` → tyle, ile jest (co najmniej 2, bo `canHost`). Trasa jest pętlą (z ostatniego punktu czempion wraca do pierwszego).
- `WorldEvents.waveSize(players: number, wave: number): number` = `math.min(max, base + perPlayer × max(1, players))`; `wave` przyda się, jeśli zdecydujesz o rosnących falach (domyślnie nie: wszystkie równe, decyzja w H2).
- `WorldEvents.scaleOf(which: "commander" | "champion", players: number): MonsterStats.Mods` = `{ hpMul = hp[clamp(players, 1, #hp)], atkMul = atk[...] }`.

**B4. Udział i nagroda.**
- `export type Contribution = { dmg: number, heal: number, shield: number, intercept: number }`.
- `WorldEvents.points(c: Contribution): number` = `dmg + heal × healMul + shield × shieldMul + intercept × interceptMul`.
- `WorldEvents.threshold(total: number, level: number): number` = `math.min(min × total, hpEquivalent × MonsterStats.baseHp(level))`, a gdy `total == 0`, to `math.huge` (nikt nie walczył, nikt nie dostaje). Uwaga: po S87 `baseHp` może już mnożyć krzywą `monsterHp`; użyj tej samej funkcji, której używa `compute` dla zwykłego potwora (bez rodzaju i wariantu), żeby próg szedł za balansem.
- `WorldEvents.eligible(points: number, total: number, eventLevel: number, charLevel: number): boolean` = `points > 0 and points >= threshold(total, eventLevel) and charLevel <= eventLevel + maxLevelAbove`.
- `WorldEvents.reward(eventLevel: number, charLevel: number, success: boolean): { exp: number, gold: number, chest: boolean }`: `exp = floor(expKills × Exp.monsterExp(eventLevel, "normal") × Exp.levelDiffMultiplier(charLevel, eventLevel) × (success ? 1 : failMul) + 0.5)`, `gold = floor(goldKills × MonsterStats.gold(eventLevel, "normal", 0.5) × (success ? 1 : failMul) + 0.5)`, `chest = success`. Na 100. poziomie EXP liczy się normalnie (to `LevelService` nic nie doda); nie zeruj go tutaj, żeby test balansu widział liczbę. Według planu S98 `monsterExpMul(L)` działa w `CombatService.reward`, nie w `Exp.monsterExp`, więc nagroda wydarzenia (osobne `GiveExp`) go **nie** zawiera: to zgodne z DESIGN-15 §4 (wydarzenie poza budżetem questów) i S98 D5; nie dokładaj go (decyzja w H2). Gdyby w kodzie mnożnik siedział jednak w `Exp.monsterExp`, nagroda go zawiera i to też jest w porządku (sprawdzenie F2 mierzy wynik); zapisz w SESJE, który przypadek zastałeś.
- `WorldEvents.rollChest(eventLevel: number, charLevel: number, classId: string?, rng): Loot.ItemDrop?`: `ilvl = ItemRoll.dropLevel(math.min(charLevel, eventLevel), rng)`, `defId = Loot.pickItem(LootTables.bossSlots, ilvl, reward.chest.classBias, classId, rng)`, rzadkość `rng:weighted(reward.chest.rarity)` (losuj po `defId`, w tej kolejności), wynik `{ defId, ilvl, rarity, forClass = classId }` albo `nil`, gdy `pickItem` nic nie dał. **D3. Inwazja.**
- Punkty fal: `WorldEvents.spawnPoints(map, area.id)` w świecie. Fala `w` (1..`waves`): `players` = gracze w fazie `playing`, żywi, na tej mapie, w promieniu `radius` od środka (płasko); `size = waveSize(players, w)`; potwory rozłóż po losowo wybranych punktach po `cluster` sztuk; rodzaj każdego z `area.kinds` bez `passive` (zając nie najeżdża), poziom `rng:int(max(area.lv[1], level - 2), min(area.lv[2], level + 1))`, wariant `"normal"`; w falach z `eliteWaves` jeden potwór dodatkowo jako `"elite"` z rodzaju z `elites ~= false`. Po spawnie: `monster.home = centre` (idą w stronę środka łowiska i tam krążą), `monster.leashRange = def.leash`, `monster.levelCap = area.lv[2]` (łup jak z łowiska, S32). `GroupSize` bez `GroupId` jest bezpieczny: `Controllers/GroupRingController.luau:37` pomija modele bez `GroupId` (fale nie mają pierścieni grup), a `Monster.new` bierze z `GroupSize` zniżkę obrażeń grupy (S32).

Po ostatniej fali albo po `commanderAt` od startu: **dowódca**. Rodzaj losowo z `hostKinds(area)`, wariant `"elite2"`, poziom `min(area.lv[2], level + 1)` (Elita II doda swoje `levelAdd`), `mods = scaleOf("commander", players)`, pozycja = `centre`; `home = centre`, `leashRange = def.leash`, `levelCap = area.lv[2]`. `bossKey = monster:Name()`; ogłoszenie `event.commander` (`AnnounceService.Server`, `{ name = "@" .. bossKey, area = ... }`). **D5. Udział, koniec i nagroda.**
- **Obrażenia:** co krok dla każdego potwora wydarzenia i każdego wpisu `monster.damageBy`: jeśli bieżąca wartość < zapamiętanej w `seen[monster][player]` (S22: `regenerate` wyczyścił `damageBy` po powrocie do pełnego HP), dodaj zapamiętaną do `bank[player].dmg`; potem `seen = bieżąca`. `CombatService.MonsterKilled:Connect(function(info) ... end)`: gdy `byEntity[info.entityId]` jest potworem wydarzenia, zrób to samo pobranie natychmiast (obiekt potwora po śmierci nadal ma `damageBy`), dopisz `seen` do `bank` i usuń potwora z list; dla fali zmniejsz `waveAlive`, dla dowódcy / czempiona ustaw `success = true` i zakończ. - **Leczenie i tarcze:** `ResourceService.Healed:Connect(function(target, amount, source, kind) ... end)`: gdy jest `current` w fazie `active`, `source` to gracz, `target` jest na mapie wydarzenia w promieniu `radius` od środka (Inwazja) albo od czempiona (czempion), dodaj `amount` do `bank[source].heal` (`"heal"`) albo `.shield` (`"shield"`).   2. `total = Σ points` wszystkich graczy w `bank`/`seen`; dla każdego gracza z `points > 0`, który jest na serwerze (`player.Parent ~= nil`) i ma postać: `ok = WorldEvents.eligible(points, total, level, char.level)`;

  4. nie `ok`, ale `points > 0`: toast `event.noReward` (za mały udział) albo `event.tooHigh` (poziom za wysoki), żeby gracz wiedział dlaczego;
  5. `AnnounceService.Server(if success then "event.end.success" else "event.end.fail", { kind = "@" .. def.nameKey, area = ..., n = liczba nagrodzonych })`;
  6. `current = nil`, gałąź `worldEvent` czyszczona u wszystkich (D6), `nextAt` (D2).
