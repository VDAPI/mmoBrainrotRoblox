### B. Czysta logika

**B1. `src/shared/Logic/Bracket.luau` (nowy, ok. 220 linii; bez `require` danych gry).** Drabinka pojedynczej eliminacji, deterministyczna, serializowalna (tablice i liczby, żeby szła gałęzią stanu):

```lua
export type Slot = { key: string?, bye: boolean? } -- key = character key "<userId>_<slot>"
export type Match = {
	id: number, round: number, a: string?, b: string?,
	winner: string?, reason: ("win" | "walkover" | "bye")?, field: number?,
}
export type Bracket = {
	size: number, rounds: number, seeds: { string }, matches: { Match },
	absent: { [string]: boolean }, eliminated: { [string]: number }, -- key -> round lost
}
```

- `Bracket.size(n: number): number` = najmniejsza potęga 2 ≥ `max(n, 2)`; `Bracket.order(size): { number }` = standardowe rozstawienie (dla 8: `1, 8, 4, 5, 2, 7, 3, 6`; dla 4: `1, 4, 2, 3`): najwyżsi rozstawieni spotykają się najpóźniej.
- `Bracket.new(seeds: { string }): Bracket`: `seeds` już posortowane (najwyższy rating pierwszy, B2 `seedOrder`); pierwsza runda wg `order`, puste miejsca to wolne losy (`bye`) i zawsze trafiają do najwyżej rozstawionych (nigdy wolny los przeciw wolnemu losowi: przy `n ≥ size / 2 + 1` to wynika z rozstawienia, test). Mecz z wolnym losem rozstrzyga się od razu (`reason = "bye"`) i wynik przechodzi do następnej rundy. `n < 2` → błąd (`error("bracket needs 2+ players")`); minimum 4 pilnuje `Logic/Tourney`, nie drabinka.
- `Bracket.ready(b): { Match }`: mecze z dwoma znanymi graczami, bez zwycięzcy, w kolejności rundy i id (serwer przydziela je polom).
- `Bracket.report(b, matchId, winner: string, reason: "win" | "walkover"): ()`: zapisuje wynik, wpisuje zwycięzcę do meczu następnej rundy, przegranego do `eliminated` z numerem rundy. Zgłoszenie dla meczu bez dwóch graczy, z innym zwycięzcą niż `a`/`b` albo już rozstrzygniętego → błąd (serwer nie może tego zrobić; test).
- `Bracket.withdraw(b, key): ()`: gracz nieobecny (wyszedł z serwera, nie pojawił się): `absent[key] = true`; jeśli ma znanego przeciwnika w nierozstrzygniętym meczu, przeciwnik wygrywa walkowerem; jeśli przeciwnik jeszcze nieznany, walkower nastąpi, gdy będzie znany (wewnątrz `report`/postępu). Obaj nieobecni → przechodzi wyżej rozstawiony z flagą `absent` (przegra walkowerem dalej; jeśli dojdzie tak do końca, `champion` zwraca `nil`).
- `Bracket.done(b): boolean`, `Bracket.champion(b): string?` (zwycięzca finału, `nil` gdy nieobecny), `Bracket.finalist(b): string?`.
- `Bracket.placeOf(b, key): number?`: 1 czempion, 2 finalista, 3 przegrani półfinałów, dalej pierwsze miejsce przedziału: przegrany ćwierćfinału 5, 1/8 → 9, 1/16 → 17 (`size / 2^(rounds − roundLost + 1) + 1`, test); `nil` dla gracza, który jeszcze gra. `Bracket.placeRange(b, place): (number, number)` (np. 5 → 5, 8) dla tekstów.
- `Bracket.view(b): any`: lekka kopia dla klienta (rundy, mecze, klucze, zwycięzcy, pole), bez `absent`/`eliminated`.

**B2. `src/shared/Logic/Tourney.luau` (nowy, ok. 200 linii; wymaga `Data/Arena`, `Data/ScheduledEvents`, `Logic/Schedule`, `Logic/ArenaRules`).** Reguły turnieju, wspólne dla serwera i okna:

- `Tourney.startAt(now): number`: start bieżącego albo najbliższego turnieju (UTC): jeśli `now` jest w oknie `[start + window.open, start + duration)` wystąpienia, to ten start, inaczej następne wystąpienie; liczone funkcjami S129 na `def = ScheduledEvents.get("tourney")`: `Schedule.current(def, now)` i `Schedule.next(def, now)` (`next(def, now - window.open)` łapie też okno zapisów przed startem; sprawdź sygnatury w kodzie). `now` zawsze z argumentu; serwer i klient podają `Clock.now()` (S129), nie `os.time()`.

Przy `#entries <= cap` wchodzą wszyscy.
- `Tourney.seedOrder(entries): { string }`: klucze posortowane wg ratingu malejąco, przy remisie wcześniejsze zgłoszenie (to samo co `pick`), dla `Bracket.new`. **Bez żadnego innego wejścia** (zasada 7, test T4).
- `Tourney.rewardsFor(place: number?, showed: boolean): { shards: number, tokens: number, title: string?, titleDays: number?, cosmetics: { string } }`: nagroda miejsca z `TOURNEY.rewards` (miejsce 3 = obaj przegrani półfinałów) plus `participantTokens`, gdy `showed`; `showed == false` (przegrał walkowerem przez własną nieobecność, zanim zagrał choć jeden mecz) → same zera (DECYZJE). Gracz, który zagrał i potem wyszedł, dostaje nagrodę miejsca, które zajął.
- `Tourney.isStale(signed, now): boolean`: zapis z `character.tourney.signed` dotyczy turnieju, który już się skończył (`signed.id ~= idOf(startAt(now))` albo faza `idle` po starcie); serwer czyści go przy wejściu postacią (D2).
