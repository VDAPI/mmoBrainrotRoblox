# Następna sesja wyglądu (gałąź `wyglad`)

Jesteś Claude Code w repozytorium gry **Vaelthorn** (Roblox MMORPG). Wykonaj następną sesję **fazy wyglądu** (`docs/WYGLAD.md` §7), od początku do końca, bez pytania mnie o nic w trakcie. Ta kolejka działa **równolegle** do kolejki mechaniki (`docs/sessions/DALEJ.md`, gałąź `main`, inny komputer albo inny folder). Nigdy nie uruchamiaj obu w tym samym folderze naraz.

1. **Gałąź.** `git fetch origin`. Jeśli lokalnie nie ma gałęzi `wyglad`: `git checkout -b wyglad origin/wyglad` (a jeśli nie ma jej też na `origin`: `git checkout -b wyglad origin/main` i `git push -u origin wyglad`). Potem `git checkout wyglad`, `git pull origin wyglad` i **`git merge origin/main`**. Przy konflikcie: w plikach mechaniki (`src/shared/Logic/*`, `src/shared/Data/Skills/*`, `Data/SkillPools/*`, `src/server/Services/*`, testy balansu) bierzesz wersję z `main`; w plikach wyglądu łączysz obie zmiany ręcznie i uruchamiasz `scripts/check`. Commit scalenia `Merge main into wyglad` i `git push origin wyglad`.
2. **Bramka oceny.** Jeśli w mojej wiadomości, którą uruchomiłem ten plik, jest ocena (np. „W01: OK” albo „W01: popraw: …”), najpierw dopisz ją jako linię w `docs/WYGLAD.md` §6 „Oceny” (pod „(puste)”, które usuwasz), commit `docs: ocena Wxx` i push. Potem otwórz `docs/WYGLAD.md` §6 „Oceny”. Jeśli ostatnia zrobiona sesja W (commit `Wxx:` na tej gałęzi) nie ma tam linii `Wxx: OK` ani `Wxx: popraw: …`, **zatrzymaj się** i napisz mi jednym zdaniem, że czekasz na moją ocenę Wxx. Jeśli jest `Wxx: popraw: …` i nie ma jeszcze commita `Wxx-popr:`, ta sesja jest poprawką Wxx: zrób dokładnie te uwagi według zasad z pliku `docs/sessions/Wxx.md`, commit `Wxx-popr: …`, push, i na tym skończ.
3. **Kolejność** (nie numeracja; pierwsza niezrobiona): **W01, W02, W11, W08, W09, W10, W12, W13, W14, W15, W16, W17, W18, W19, W20, W21, W22, W23, W24, W25, W26, W27, W03, W04, W05, W06, W07, W28, W29**. Sesja jest zrobiona, jeśli `git log` na tej gałęzi ma commit zaczynający się od `Wxx:` albo `docs/wyglad/SESJE-W.md` ma nagłówek `### Wxx`. **W03–W07 wymagają S148 na `main`** (`git log origin/main --oneline | grep " S148:"`): jeśli jej nie ma, a wszystko przed W03 jest zrobione, napisz mi, że faza wyglądu czeka na koniec nowych umiejętności, i nic nie zmieniaj. Jeśli brakuje pliku `docs/sessions/Wxx.md`, zatrzymaj się i napisz mi, że trzeba go dopisać (pliki powstają po kolei, po ocenach).
4. Przeczytaj `docs/WYGLAD.md` w całości, potem cały `docs/sessions/Wxx.md`, i wykonaj go dokładnie tak, jakbym wkleił go jako pierwszą wiadomość. Obowiązują zasady fazy gameplay z `CLAUDE.md` (`scripts/check` zielony, decyzje na końcu `docs/wyglad/DECYZJE-W.md`, sekcja sesji na końcu `docs/wyglad/SESJE-W.md`, stan w `docs/wyglad/STAN-W.md` (osobne pliki fazy wyglądu, żeby scalanie z `main` nie dawało konfliktów; `docs/DECYZJE.md`, `docs/SESJE.md` i `docs/PROGRESS.md` zostają dla kolejki mechaniki)) oraz wyjątek Studio MCP z `docs/DESIGN-16.md` §0.1 dla sesji W. **Commit `Wxx: …` i `git push origin wyglad`. Nigdy nie pushuj na `main`**: na `main` trafia to dopiero po mojej ocenie, przez PR.
5. Zrób tylko tę jedną sesję. Na koniec napisz w 5–10 liniach: którą sesję zrobiłeś, co zobaczę na zrzutach i gdzie (nazwy `capture_id` albo opis scen), co zostało w „Niedokończone”, i poproś mnie o ocenę: „Wxx: OK” albo co poprawić.
