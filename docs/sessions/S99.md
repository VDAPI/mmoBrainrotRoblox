Reguły:
- **Kandydaci na poziom L:** łowiska ze wszystkich czterech map regionów (`Areas.byMap[mapId].areas`, w kolejności `REGION_MAPS`, w mapie posortowane jak `AreaAdvice.sorted`), z `area.groups >= rules.minGroups` i `area.lv[1] <= L <= area.lv[2]`. - `build` przechodzi L = 1..`Contracts.MAX_LEVEL` (99).
- `reward.exp = math.floor(Exp.expToNext(L) × share)` (jak `Daily.reward`), `reward.gold = math.floor(gold.base + gold.perLevel × L)`, `reward.items = rules.milestones[L]` (kopie tablic) albo brak pola.
- Rekord jak w A2 (bez `givers`; `objectives = { { type = "kill", n = n, area = area.id } }`, **bez** `monster`, `region` i `variant`: liczy się każdy potwór z grup tego łowiska, także w drużynie, bo `credit` z `CombatService` dostaje każdy zaliczony).
