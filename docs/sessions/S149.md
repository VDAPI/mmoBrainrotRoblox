### B. Harmonogram (nowy czysty `src/shared/Logic/WorldBoss.luau`)

1. `WorldBoss.occurrenceAt(t) -> { id, startsAt, endsAt }?`: termin, w którym `t` leży między `startsAt − warn[1]` a `endsAt + linger`; `id = "wb" .. "YYYYMMDDHH"` (godzina UTC startu, `Schedule.dateKey` + godzina), `endsAt = startsAt + boss.timeLimit`.

4. `WorldBoss.phase(occ, now) -> "warn" | "active" | "gone"` (do gałęzi stanu i serwisu).
5. Bez `os.time`, bez API Roblox; czas tylko z argumentu.
