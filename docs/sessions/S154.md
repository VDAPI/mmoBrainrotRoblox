## Kontekst

- **Co gra rysuje dziś:** tylko broń i drugą rękę w dłoni (`EquipmentService.updateHeldModel` → `Util/WeaponBuild.attach(model, def.type, accent, name, def)`: model progu z `ArtTiers.modelId(def, has)` albo bryły `WeaponLooks` typu; kolor `"rarity"` i poświata Heroiczny+ z rzadkości przedmiotu; klejnot żywiołu broni maga). Zbroja i biżuteria **nie są rysowane** (postać nosi strój klasy z `Data/ClassLooks` albo strój z garderoby; S132 zostawiła `layers` na później). Dlatego transmog obejmuje **typy z wpisem w `WeaponLooks`** (broń i druga ręka: tarcze, kołczany, księgi, kule, relikwie), a zbroję i biżuterię dopiero z warstwami zbroi (linia w DECYZJE; `Transmog.SLOTS` liczone z danych, więc dojdą same).
- **Ikony:** `Logic/ItemIcons` (`eq/<type>@<tier>` najbliższego niższego progu z obrazkiem przez `ArtTiers.iconKeys`, przedmioty bossów własne).
- **Przedmioty bossów:** nazwane z `fixedBonuses` (`Data/Items/Uniques`), własny model pod `def.id` w `WeaponLooks.assets` (`ArtTiers.modelId` sprawdza `def.id` najpierw), wypadają rzadko (Mityk z bossa, drabina S87 / S94). To są **rzadkie wyglądy z bossów**: kolekcja dostaje je tylko przez posiadanie takiego przedmiotu.
- **Kowal:** `BlacksmithService` (`nearSmith`, `locate(player, "eq"|"inv", key)` z `commit`, `takeMaterials`, `addGold`, serwerowy `rng`), okno `BlacksmithWindow/` z zakładkami (po S134j: `craft`, `upgrade`, `dismantle`, `reroll`) i wspólnym modułem wyboru przedmiotu (S134j C1). Złoto ulepszeń `Upgrade.goldPerIlvl(ilvl)` (`Config.Upgrade`).
- **Garderoba:** `UI/Screens/Wardrobe.luau` (dwa poziomy zakładek S123, grupy `Cosmetics.KINDS` / `Group`), kosmetyk `weapon` = cząsteczki na części głównej broni (`VaelthornWeapon`).

### A. Logika `src/shared/Logic/Transmog.luau` (czysta)

1. `Transmog.SLOTS`: typy z `WeaponLooks.get(type) ~= nil` (broń i druga ręka); `Transmog.supports(def) -> boolean`.
2. **Klucz wyglądu** `Transmog.lookOf(def) -> string`: przedmiot z własnym modelem (`has(def.id)` w `WeaponLooks.assets`) → `"<def.id>"` (wygląd bossa / unikatu); inaczej `ArtTiers.modelId(def, has)` → `"<type>_<t>"` (model progu); bez modelu → `"<type>"` (wygląd z brył — jeden na typ, nie po jednym na próg, żeby kolekcja nie miała dziesięciu identycznych pozycji; linia w DECYZJE). `has` = `WeaponLooks.assets` (dane, działa w Lune).
3. `Transmog.lookType(key) -> string?` (typ wyglądu), `Transmog.lookDef(key) -> ItemDef?` (definicja do rysowania i nazwy: przedmiot `def.id` albo pierwszy próg typu z tym modelem / najniższy próg typu), `Transmog.isBoss(key) -> boolean` (wygląd przedmiotu z `fixedBonuses`).
4. `Transmog.unlocks(items: { ItemInstance }) -> { string }`: klucze wyglądów przedmiotów z obsługiwanych typów (do skanu i odblokowania).
5. `Transmog.canApply(item, key, looks) -> (boolean, string?)`: przedmiot obsługiwany (`transmog.error.type`), wygląd odblokowany (`transmog.error.locked`), ten sam typ (`lookType(key) == def.type`, `transmog.error.mismatch`), nie ten sam co obecny (`transmog.error.same`; własny wygląd przedmiotu = zdjęcie, nie nałożenie). `key = ""` = zdjęcie (zawsze wolno, darmowe).
6. `Transmog.cost(item) -> { gold: number, materials: { { id, n } } }` z `Config.Transmog = { goldMul = 1.5, essence = { [2] = { "essence_dust", 2 }, [3] = { "essence_shard", 1 }, [4] = { "essence_crystal", 1 }, [5] = { "essence_crystal", 1 } } }` (start; klucz = rzadkość docelowego przedmiotu; Zwykły bez esencji): złoto `floor(ilvl × Upgrade.goldPerIlvl(ilvl) × goldMul + 0,5)`. Wygląd bossa na przedmiocie nie kosztuje więcej (linia w DECYZJE: rzadkość wyglądu to nagroda za bossa, nie dodatkowy podatek).
7. `Transmog.apply(item, key) -> ItemInstance` (nowa tabela: `tm = key` albo `nil` przy `""`), `Transmog.displayDef(item) -> ItemDef` (definicja wyglądu, gdy `tm` ważny i tego samego typu, inaczej własna — zabezpieczenie po zmianie danych: wygląd znikniętego modelu wraca do własnego, bez błędu).
8. `Transmog.sanitize(state)` dla `account.transmog` (tylko klucze, które `lookType` zna).
9. `tests/transmog.spec.luau`: `SLOTS` (broń i druga ręka tak, zbroja / biżuteria / materiał nie), `lookOf` (model bossa, model progu, bryły jednym kluczem na typ), `canApply` (wszystkie błędy, zdjęcie), `cost` (rośnie z ilvl, esencja według rzadkości, Zwykły bez esencji), `apply` (zmienia się tylko `tm`; `uid`, `id`, `rarity`, `ilvl`, `bonuses`, `up`, `bound`, `locked`, `el`, `fx`, `rv`, `rr` nietknięte — porównanie głębokie), `displayDef` (zły typ / nieznany klucz → własny), `ItemScore` i `StatCalc` tego samego przedmiotu z `tm` i bez dają ten sam wynik (zasada 4).

### B. Serwer

1. **Kolekcja (konto):** odblokowanie przy wejściu przedmiotu do plecaka lub ekwipunku (`InventoryService.Changed` / `EquipmentService.Changed` albo miejsca `AddItem` i założenia — wybierz to, co obejmuje łup, pocztę, handel, nagrody i kowala; linia w DECYZJE), dopis `account.transmog.looks[key] = true` (zapis tylko nowych kluczy) i toast `transmog.unlocked` „Nowy wygląd w kolekcji: {name}” (dla wyglądów bossa wyróżniony). **Skan jednorazowy** przy pierwszym wczytaniu po S154 (`scanned = false`): plecak, ekwipunek i depozyt wszystkich postaci konta (bez poczty i aukcji). Odblokowanie zostaje po sprzedaży / rozbiciu przedmiotu.
2. **Nałożenie:** remote `TransmogApply = { kind = "function", dir = "c2s", rate = 2, args = { "string", "string", "string", "string" } }, -- ("inv"|"eq", key, look key or "" to remove, expected item uid)`. `BlacksmithService.transmog(player, location, key, look, uid)` wzorem `reroll`: `IsTradeLocked`, postać, `nearSmith`, `locate`, uid zgodny (`transmog.error.changed`), `Transmog.canApply`, koszt (pomijany przy zdjęciu), złoto `shop.error.gold`, materiały `smith.missing`; bez yieldów: pobranie, `Transmog.apply`, `commit()`; założony przedmiot → przebudowa wyglądu w ręce (B3). `Analytics.custom(player, if boss then "TransmogBoss" else "Transmog", item.rarity)` (dwie stałe nazwy, wartość = rzadkość; `custom` przyjmuje liczbę), log.
3. **Wygląd w ręce:** `EquipmentService.updateHeldModel` rysuje `Transmog.displayDef(item)` zamiast `def` (typ ten sam, więc chwyt, `WeaponType` i animacje S113 / S115 bez zmian), kolor `"rarity"`, poświata i klejnot żywiołu **z przedmiotu**, nie z wyglądu. Podgląd `/weaponpreview` bez zmian.
4. **Przedmiot wędruje z wyglądem:** `tm` przechodzi przez handel, pocztę, aukcję i depozyt (cały przedmiot jest zapisywany); kupujący nie dostaje wyglądu do kolekcji, dopóki nie odblokuje go sam (kolekcja liczy `lookOf(def)` przedmiotu, nie `tm`); może zdjąć wygląd za darmo. Linia w DECYZJE.
5. **Admin:** `/transmog <slot|index> <key|clear> [free]`, `/transmoglooks [all|clear|list]` w `Data/AdminCommands.luau` (kategoria przedmiotów) + `run` w `src/server/Admin/Items.luau` + `admin.usage.transmog`, `admin.usage.transmoglooks` (PL, EN).
