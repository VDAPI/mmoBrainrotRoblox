## A. Szkielet eksportera (najpierw, z testem)

1. `tools/WikiData/` — czyste moduły bez `fs` (testowalne): `init.luau` z `build(opts) -> { files: { [path]: string }, stats }` (`opts.rolls`, `opts.only`), `Clean.luau`, `Json.luau`, `Schema.luau`, `Names.luau`, `Features.luau`, `Leak.luau`, `StubRng.luau`, po jednym module na grupę plików (`Items`, `Monsters`, `Bosses`, `World`, `Quests`, `Skills`, `Crafting`, `Upgrade`, `Basics`, `Search`) oraz `TypesTs.luau`, `TokensCss.luau`, `ItemsMd.luau`. `World.build()` ma być używalne też przez `tools/wikimap.luau` z S37.
2. `tools/wikidump.luau` — CLI: `lune run tools/wikidump.luau [--out wiki/src/data] [--rolls 100000] [--only items,monsters] [--check]`. Uruchamiany z katalogu repo (inaczej czytelny błąd „uruchom z katalogu repozytorium”); tworzy foldery (`fs.writeDir`), pisze pliki, drukuje tabelę rozmiarów. `--check` nic nie zapisuje, porównuje z plikami na dysku i kończy kodem 1 przy różnicy (pod S44).
3. `Clean.clean(v, path)`: funkcje usuwa, gęste tablice `1..n` → tablice, rzadkie klucze liczbowe → klucze tekstowe, **mieszane → błąd** ze ścieżką (nie gub danych po cichu), cykle → błąd.
4. `Json.encode`: klucze posortowane, liczby całkowite bez kropki, reszta do 4 miejsc (albo `decimals` z schematu), bez `-0`, NaN/inf → błąd, `\n` jako koniec linii; rekordy najwyższego poziomu po jednym w linii (czytelne diffy, mały rozmiar).
5. `Schema.luau`: jedna deklaracja każdej encji (pole → typ: `string`, `int`, `number`, `bool`, `name` = `{pl,en}`, `ref:<plik>`, tablica, mapa, opcjonalność). Z niej: walidacja wyjścia (klucz spoza schematu → błąd), `types.ts` i tabela do `docs/WIKI.md` §5.
6. `Names.of(key)` → `{ pl, en }` przez `Locale.T(key, nil, lang)`, brak (`Locale.has`) zgłaszany do listy błędów. Przedmioty: `ItemName.get(lang, id)`, broń maga dodatkowo dla każdego `Elements.WEAPON`.
7. `StubRng`: obiekt z metodami `Rng` (`next`, `int`, `float`, `chance`, `weighted`, `pick`, `shuffle`) zwracającymi skrajne wartości (tryb `min`/`max`/`fail`). Monte Carlo: `Rng.new(seed)`, ziarno = stały hash z `"<kind>:<variant>"` (dodanie potwora nie zmienia innych wyników). Wszędzie iteruj po posortowanych id, nie w kolejności `pairs`.
8. Flagi niewydanych: encja z `hidden == true` albo `wiki == false` znika razem z odwołaniami (łupy, sklepy, nagrody, sąsiedzi); czysta funkcja testowana na fikcyjnych danych.
