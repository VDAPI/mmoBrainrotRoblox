Formatowanie pl/en z `src/lib/format.ts`. HTML: `<span class="vw-stat" data-src="…" title="Z danych gry: …">` (tabular-nums, przerywane podkreślenie `--vw-gold-dark`). Logika w `src/lib/stat.ts` (`resolveStat(path)`, `formatStat(v, format, lang)`), testowana.
   - `<Item id n? rarity? up? />`: `ItemIcon` 20 px + nazwa w kolorze tekstowym rzadkości (`--vw-r-<key>-text`), link przez `sectionHref(lang, "items", id)`, `×n`; pływający tooltip, jeśli helper istnieje. `<Monster id variant? />` (nazwa wariantu + mały `RankBadge` dla elit, link do bestiariusza), `<Quest id />`, `<Npc id />` („rola · imię”, link z `npcHref`; gdy `npcs.json` nie ma jeszcze `role`, które dopisze S43, samo imię), `<Region id area? />` (nazwa + poziomy, link do krainy), `<Rarity id />` (`RarityBadge`), `<Key action="win_map" />` (`.vw-kbd` z domyślnym klawiszem z `mechanics.keybinds`), `<Link to="upgrading" id?>tekst</Link>` (`sectionHref`, niegotowe → tekst z „Wkrótce”), `<Spoiler title?>` i `<Callout kind title? date? update?>` (`Callout` z S36; nowy prop `update` linkuje do `/pl/aktualizacje/#<slug>`, a do czasu `SECTIONS.updates.ready` z S43 pokazuje samą datę bez linku — dopisz w „Komponenty”).
