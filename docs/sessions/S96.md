## Kontekst

Właściciel chce od 20. poziomu własnego wierzchowca, żeby szybciej poruszać się po mapie: da się na nim jeździć, z siodła wolno bić, ale nie wolno używać umiejętności (cytat na końcu). Kontrakt `docs/DESIGN-15.md` §2 doprecyzowuje: podstawowy koń z łuku trzech zadań u stajennego, `WalkSpeed = 16 × mnożnik(poziom wierzchowca) × (1 + moveSpeed ze sprzętu)` z mnożnikiem 1,6 → 2,0 liniowo na poziomach 1–10 i tym samym limitem +30% sprzętu co pieszo; buffy szybkości z umiejętności nie działają, sprint nie, spowolnienia tak (powód z kontraktu: bez premii ze sprzętu piechur z +30% i sprintem, 28,1 st./s, byłby szybszy niż koń 1. poziomu, 25,6; z regułą koń 1. poziomu z tym samym sprzętem jedzie 33,28); wsiadanie 1,5 s (od 5. poziomu wierzchowca 1,0 s) przerywane ruchem, obrażeniami i umiejętnością; w walce nie wsiądziesz; użycie umiejętności zsiada i umiejętność się wykonuje; jazda tylko w mieście i otwartych regionach. Poziomy wierzchowca istnieją już w zapisie i we wzorze szybkości, ale podnosi je dopiero S97 (u stajennego); w tej sesji koń ma poziom 1, a admin może ustawić inny.

**B1. `src/shared/Logic/Mounts.luau` (nowy, czysty, ok. 180 linii).** Wymaga `Config`, `Data/Mounts`, `Data/Maps`, `Data/Stats`. API:

```lua
export type Owned = { [string]: { lvl: number } }
export type MountState = { owned: Owned, active: string?, riding: boolean }
export type Reason = "dead" | "level" | "none" | "riding" | "combat" | "place" | "busy"
export type CheckInput = {
	level: number, -- character level
	mounts: MountState?,
	dead: boolean,
	inCombat: boolean,
	mapId: string,
	zoneKey: string?, -- ZoneService nameKey
	busy: boolean, -- travel / gather / fishing / quest use / skill channel running
}
export type Seat = { hipHeight: number, offset: { number } } -- offset: LookRoot centre from the rider's root centre

function Mounts.speedMul(lvl: number?): number
function Mounts.mountTime(lvl: number?): number
Mounts.GEAR_SOURCE = "source.gear" -- StatCalc source key of equipment (EquipmentService modifierSource)
function Mounts.gearMove(parts: { { key: string, value: number, pct: boolean? } }?): number -- gear moveSpeed points, 0..cap
function Mounts.walkSpeed(input: { riding: boolean, lvl: number?, walk: number, gearMove: number, sprint: boolean, factor: number }): number

function Mounts.canMount(input: CheckInput): Reason?
function Mounts.grant(state: MountState, id: string): boolean -- adds { lvl = startLevel }, sets active when nil
function Mounts.seat(rig: { root: { size: { number } }, hipHeight: number, sockets: { [string]: { pos: { number } } } }, rootHalf: number): Seat
```

Zasady:
- `speedMul(lvl)` = `baseMul + (maxMul − baseMul) × (clamp(lvl or 1, 1, maxLevel) − 1) / (maxLevel − 1)`; 1 → 1,6, 10 → 2,0, 5 → ok. 1,7778. Nigdy powyżej `maxMul` (sufit wspólny dla wszystkich wierzchowców, także tych z S97).
- `mountTime(lvl)` = `mountTimeFast`, gdy `lvl >= fastFromLevel`, inaczej `mountTime`.
- `gearMove(parts)`: suma `value` części z `key == GEAR_SOURCE` i bez `pct`, przycięta do 0..`Stats.get("moveSpeed").cap` (30); `nil` → 0.
- `walkSpeed(input)`: jazda → `Stats.Formula.walkSpeed × speedMul(lvl) × (1 + clamp(gearMove, 0, cap) / 100) × factor` (**bez** `walk`, czyli bez buffów i pasywek, i bez sprintu); pieszo → `walk × (sprint and Config.SprintMultiplier or 1) × factor` (dokładnie dzisiejsza reguła po S63; `walk` = `result.walkSpeed`). `factor` to czynnik spowolnień z S63 (0..1). To jedyny wzór szybkości chodu gracza; `StatService` go woła (D3).
- `allowedAt(mapId, zoneKey)`: mapa istnieje, jej `biome` nie jest w `RULES.noBiomes`, a `zoneKey` nie jest w `RULES.noZones`. Nieznana mapa → `false`.
- `activeOf`: `active`, gdy jest w `owned`; inaczej pierwszy posiadany po posortowaniu id; poziom = `owned[id].lvl` przycięty do 1..`maxLevel`; brak → `nil, 0`.
- `canMount(input)` w tej kolejności: `dead` → `"dead"`; `level < Config.Mount.minLevel` → `"level"`; brak wierzchowca (`activeOf` nil) → `"none"`; `mounts.riding` → `"riding"`; `inCombat` → `"combat"`; `not allowedAt` → `"place"`; `busy` → `"busy"`; inaczej `nil`. Komunikat to `mount.error.<reason>` (H), poza `"riding"` (serwer wtedy po prostu nic nie robi).
- `grant(state, id)`: nieznane id albo już posiadane → `false` bez zmian; inaczej `owned[id] = { lvl = def.startLevel }`, `active = active or id`, `true`. Każda postać dostaje konia z łuku raz, bo zadanie da się oddać raz; drugie przyznanie (admin) nie zeruje poziomu.
- `seat(rig, rootHalf)`: środek `LookRoot` konia jest `H0 = rig.hipHeight + rig.root.size[2] / 2` nad ziemią; siodło (socket `Saddle`, pozycja względem środka rdzenia) na wysokości `H0 + s[2]`; środek korzenia jeźdźca `Hr = H0 + s[2] + RIDER.seatLift`; wynik `hipHeight = Hr − rootHalf`, `offset = { −s[1], H0 − Hr, −s[3] }` (koń przesunięty tak, żeby siodło było pod jeźdźcem, kopyta na ziemi). Prawdziwy model (D1) liczy to samo z `MountAsset.saddle`.

Powód → `false, "mount.error.<reason>"`. Inaczej start wsiadania: `token`, gałąź stanu `mountCast = { endsAt = Workspace:GetServerTimeNow() + t, duration = t, label = "mount.casting" }` z `t = Mounts.mountTime(lvl)`, `StatService.SetSprint(player, false)`; pętla co 0,1 s (wzór `TravelService.channel` 190–232): token zmieniony → koniec; postać nie żyje, brak korzenia albo przesunięcie > `Config.Mount.moveLimit` → przerwanie z toastem `mount.interrupted`; po czasie ponowne `canMount` (walka i miejsce mogły się zmienić; atak podstawowy w trakcie oznacza walkę, więc wsiadanie się nie uda) i `Ride`.
- **Przerwania:** `ResourceService.Damaged` z `amount > 0` → `Interrupt` + toast `mount.interrupted`; `SkillService` przed rzutem woła `Interrupt` (D4); `Request(player, false)` w czasie wsiadania przerywa bez toastu.
- **`Ride(player, force)`:** `MountLook.build`; brak korzenia albo modelu → nic. Zapamiętaj `humanoid.HipHeight`, ustaw `humanoid.HipHeight = seat.hipHeight` (`rootHalf = root.Size.Y / 2`), ustaw `model:PivotTo(root.CFrame * CFrame.new(offset))`, przyspawaj `LookRoot` do `HumanoidRootPart` (`Weld`, `C0 = CFrame.new(offset)`, rodzic: model wierzchowca), rodzic modelu: `player.Character`. ### G. Admin `/mount`

`cmd("character", "mount", { enum("action", { "info", "give", "take", "lvl", "ride", "off" }), str("arg", true) })` w `Data/AdminCommands.luau` (blok S96 pod `sprint` / `speed`), `commands.mount` w `Admin/Character.luau`, `admin.usage.mount` w PL i EN. Działania:
- `info`: posiadane (`id lvl`, przecinkami), aktywny, `riding`, bieżące `WalkSpeed`, `Mounts.speedMul(lvl)` i `Mounts.mountTime(lvl)` aktywnego (`admin.mount.info`);
- `give [id]` (domyślnie `mount_horse`): `MountService.Grant` (`admin.mount.given` albo `admin.mount.already`); nieznane id → `admin.mount.unknown`;
- `take [id]`: usuwa z `owned` (zsiada, poprawia `active`) (`admin.mount.taken`);
- `lvl <n>`: poziom aktywnego 1..`maxLevel` (`admin.mount.lvl`), od razu `RefreshWalkSpeed`;
- `ride`: `MountService.Ride(player, true)` (bez czasu, poziomu i walki; miejsce obowiązuje: wtedy `mount.error.place`);
- `off`: `Dismount(player, "admin")`.
Odpowiedzi przez `reply`. Komenda nie ma wpływu na innych graczy, więc bez `danger`.
