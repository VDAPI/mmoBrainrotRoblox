## Przepustka sezonu a VIP (pytanie właściciela: „a to nie jest VIP?”)

Nie. To dwie różne rzeczy i obie zostają; ta różnica idzie do `docs/DESIGN.md` (nowy §21b), na wiki (S152b) i do DECYZJE:

| | VIP (S121) | Przepustka sezonu (S152) |
|---|---|---|
| Co to jest | subskrypcja Roblox co miesiąc | jednorazowy zakup na jeden sezon (8 tygodni) |
| Za co | Robux (subskrypcja) | Smocze Odłamki (kupione za Robux), raz na sezon na konto |
| Co daje | stałe udogodnienia, dopóki płacisz: 15 odłamków dziennie, darmowy powrót, darmowe odrodzenie, kosmetyk miesiąca, aukcja | **nic samo z siebie**: odblokowuje drugą ścieżkę nagród, które trzeba **wygrać grą** (punkty sezonu) |
| Zależy od gry | nie (działa od pierwszego dnia) | tak (bez grania nie ma stopni ani nagród) |
| Po końcu | korzyści gasną po wygaśnięciu subskrypcji | zdobyte kosmetyki zostają na zawsze; nowy sezon = nowa przepustka |
| Ścieżka darmowa | — | każdy gracz, bez płacenia |

VIP **nie** przyspiesza punktów sezonu i nie daje premium przepustki (linia w DECYZJE: dwa niezależne produkty, bez „VIP ma przepustkę”). Przepustka **nie** daje odłamków (nie „zwraca się”), stopni nie da się kupić (bez „kup 10 stopni”).

Ponad limit punkty przepadają (UI pokaże „Limit tygodnia osiągnięty”).
5. `CATCHUP = { mul = 1.5, behind = 0.6 }`: gdy stopień konta jest niższy niż `behind × tiers × w / weeks` (w = tydzień sezonu), każde źródło daje ×`mul` (zaokrąglenie w dół), do dogonienia linii. Limit narastający dalej obowiązuje.
6. `GRACE_DAYS = 14`: po końcu sezonu nieodebrane nagrody (darmowe i premium, jeśli kupiona) odbiera się jeszcze w oknie przez 14 dni; potem przy pierwszym wejściu przychodzą **pocztą** (klucz `once` = `season_<id>_<userId>`). Kosmetyki z poczty przyznaje odbiór listu (sprawdź, czy poczta umie kosmetyk; jeśli nie — kosmetyki przyznaje serwis od razu, a pocztą idą tylko przedmioty; linia w DECYZJE).
7. Eksport: `Seasons.list`, `Seasons.get(id)`, `Seasons.at(now) -> SeasonDef?` (trwający), `Seasons.next(now) -> SeasonDef?`, `Seasons.lastEnded(now)`. Bez API Roblox.

### B. Logika `src/shared/Logic/Season.luau` (czysta) + `tests/season.spec.luau`

1. Stan na koncie: `account.season: { id: string, points: number, day: number, dayKill: number, premium: boolean, free: { [number]: boolean }, prem: { [number]: boolean }, mailed: { [string]: boolean } }` (typ w `Types.luau`, komentarz `-- S152`). `Season.sanitize(state)`: śmieci → wartości domyślne, `points` całkowite ≥ 0, mapy tylko liczbowe klucze 1..tiers z `true`.
2. `Season.roll(state, now) -> state`: gdy `state.id` ≠ id trwającego sezonu, zwraca czysty stan nowego sezonu (stary zostaje do rozliczenia w C5: `Season.unclaimed(oldState, def)` przed rollem). Bez sezonu: stan z `id = ""`.
3. `Season.week(def, now) -> number` (1..weeks, 0 przed startem), `Season.ends(def) -> number`, `Season.tierOf(points, def) -> number` (`floor(points / TIER_POINTS)`, maks. `tiers`), `Season.progress(points)` (punkty w bieżącym stopniu), `Season.capAt(def, now) -> number` (`weekCap × week`).
4. `Season.add(state, def, source, now, n?) -> (state, gained: number, reason: string?)`: punkty `POINTS[source] × (n or 1)`, nadrabianie (A5), limit dzienny potworów (A4, licznik `dayKill` z dniem UTC), limit narastający (A4); powody: `"cap"`, `"killCap"`, `"noSeason"`, `"unknown"`. Nigdy nie zmienia wejścia.
5. `Season.canClaim(state, def, tier, track) -> (boolean, string?)`: stopień osiągnięty, nagroda istnieje, nieodebrana, `premium` tylko z kupioną przepustką; błędy `season.error.tier`, `.claimed`, `.noPremium`, `.noReward`, `.ended` (po `GRACE_DAYS`). `Season.claim(state, tier, track) -> state`. `Season.claimable(state, def) -> { { tier, track } }` (dla „Odbierz wszystko” i kropki na HUD w S152b).
6. `Season.canBuy(state, def, now) -> (boolean, string?)`: trwający sezon i jeszcze niekupiona; kupić można aż do ostatniej sekundy sezonu (wszystkie zdobyte stopnie premium odbiera się wstecz; linia w DECYZJE); błędy `season.error.owned`, `.noSeason`.
7. `Season.unclaimed(state, def) -> { Reward }` (do poczty po okresie łaski).
8. Testy: sanitize (śmieci), roll (nowy sezon czyści stan), week / tierOf / capAt na granicach (poniedziałek 00:00 UTC, ostatnia sekunda sezonu), add (limit dzienny potworów i reset o północy UTC, limit narastający: tydzień 1 → 6500, tydzień 3 → 19 500, nadrabianie ×1,5 do linii i bez nadrabiania nad linią, źródło nieznane), canClaim (wszystkie błędy, premium wstecz po zakupie), claimable, unclaimed, canBuy. Ziarno niepotrzebne (bez losowości).
