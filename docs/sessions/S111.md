### A. Rejestr dźwięków

**A1. `src/shared/Data/Sfx.luau` (nowy).** Kształt (DESIGN-16 §3 plus `hint`, wzór `Data/Ambience`):
```lua
export type Def = {
	ids: { string }, -- "rbxassetid://<digits>" variants; empty = silent (the fallback chain picks another key)
	volume: number, -- 0..1 before the group and priority scaling
	pitch: { number }, -- { min, max } PlaybackSpeed, e.g. { 0.94, 1.06 }
	roll: number, -- RollOffMaxDistance in studs (ignored by 2D keys)
	cooldown: number?, -- seconds before the same key may play again from the same source (hurt, aggro, roar)
	hint: string, -- what to look for in the Creator Store (search words), kept after the ids are filled
	ui: boolean?, -- 2D (no position): interface sounds
}
local Sfx = {}
Sfx.defs = {} :: { [string]: Def }
function Sfx.get(key: string): Def?
function Sfx.has(key: string): boolean -- defined (even with empty ids)
function Sfx.playable(key: string): boolean -- defined and at least one id
Sfx.MATERIALS = { "flesh", "armor", "wood", "stone", "bone", "slime" }
Sfx.FAMILY_MATERIAL = { animal = "flesh", humanoid = "armor", undead = "bone", beast = "flesh", elemental = "stone", dragon = "armor" }
return Sfx
```
Pomocnik w pliku: `local function d(hint: string, volume: number, roll: number, extra: { pitch: { number }?, cooldown: number?, ui: boolean? }?): Def` z domyślnym `pitch = { 0.94, 1.06 }` (±6%, DESIGN-16 §3: 5–8%) i `ids = {}`.
