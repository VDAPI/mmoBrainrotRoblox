### B. Generator tekstur `tools/vfx/make_textures.py`

**B1. Zasady generatora.**
- Python 3 + **tylko Pillow** (bez numpy, bez sieci, bez Playwright). Jeśli Pillow brak: `pip install pillow` (jak `tools/icons/README.md`); jeśli i to się nie uda, generator zostaje w repo, `art/vfx` pusty, wpis w „Niedokończone”, gra działa na zapasach.
- **Deterministyczny:** każda tekstura ma własne ziarno `seed = int(sha256(key).hexdigest()[:8], 16)` i własny `random.Random(seed)`; zero `time`, `os.urandom`, `Image.effect_noise` (używa nieziarnionego generatora C). Szum to własny „value noise”: siatka losowych wartości z `Random`, powiększona `Image.resize(..., Image.BICUBIC)`, suma 2–4 oktaw.
- **Format:** RGBA, kolor zawsze biały `(255, 255, 255)`, kształt tylko w kanale alfa (gra barwi przez `Color`/`Color3`). Wyjątek: brak. Krawędzie wygładzone: rysowanie w 4× rozdzielczości i `resize(..., Image.LANCZOS)` (helper `supersample`). Zapis bez metadanych (`img.save(path, "PNG")` bez `pnginfo`).
- **Skrócony hash obrazu w manifeście liczony z pikseli** (`sha256(img.tobytes())`), nie z pliku: inna wersja Pillow może inaczej kompresować PNG, piksele zostają te same.
- Helpery (jeden plik, ok. 400–600 linii, albo `make_textures.py` + `vfx_draw.py` obok): `rng_for(key)`, `canvas(w, h)`, `supersample(draw_fn, w, h, k=4)`, `radial_alpha(size, falloff, power)`, `value_noise(rng, w, h, cells, octaves)`, `blur(img, radius)` (`ImageFilter.GaussianBlur`), `alpha_to_rgba(mask)`, `tile_check(img)` (lewa i prawa krawędź tekstur `Wrap` mają te same kolumny alfa ±2/255), `grid(frames, cols, frame_size)` (składa flipbook).

**B2. CLI.**
```
python tools/vfx/make_textures.py                 # rysuje wszystko do art/vfx/, pisze art/vfx/manifest.json
python tools/vfx/make_textures.py --only glow,smoke
python tools/vfx/make_textures.py --check         # rysuje w pamięci i porównuje hash pikseli z manifestem; kod 1 przy różnicy
python tools/vfx/make_textures.py --preview build/vfx_preview.png   # arkusz podglądu (B3)
```

### C. Rejestr, moduł tekstur, pula i limity

**C1. `src/shared/Data/VfxTextures.luau` (nowy, Data, bez API Roblox):**
```lua
--!strict
-- Effect textures (S112, DESIGN-16 §4): white-on-transparent PNGs drawn by tools/vfx/make_textures.py into art/vfx/
-- (manifest art/vfx/manifest.json) and uploaded as images. `id` is filled in by hand after the upload
-- (docs/ANIMACJE.md, "Tekstury efektów"); an empty id keeps the old look (neon parts, the default particle), so the
-- game works before and after the upload. The client tints every texture with the effect's colour.

export type Kind = "particle" | "beam" | "trail" | "decal"
export type Grid = "2x2" | "4x4" | "8x8"
export type Mode = "loop" | "oneShot" | "pingPong" | "random"

export type Texture = {
	id: string, -- "rbxassetid://<digits>" or "" (not uploaded yet)
	file: string, -- file name in art/vfx/
	w: number,
	h: number,
	kind: Kind,
	grid: Grid?, -- flipbook layout (particles only)
	frames: number?, -- frames of the flipbook (4 for 2x2, 16 for 4x4, 64 for 8x8)
	mode: Mode?, -- flipbook playback
	emission: number?, -- default LightEmission (0..1; smoke and dust 0, sparks and glow 1)
	wrap: boolean?, -- beams / trails: the texture tiles along U (TextureMode Wrap)
}

local list: { [string]: Texture } = {
	glow = { id = "", file = "glow.png", w = 256, h = 256, kind = "particle", emission = 1 },
	smoke = { id = "", file = "smoke.png", w = 1024, h = 1024, kind = "particle", grid = "4x4", frames = 16, mode = "oneShot", emission = 0 },
	-- ... every key of B5, in the generator's order
}

-- Keys in the generator's order (tests compare them with the manifest).
local ORDER = { "glow", "spark", "star", "smoke", "fire", "dust", "slashWide", "slashNarrow", "ring", "cracks",
	"runeWarrior", "runeHunter", "runeMage", "runeCleric", "magicCircle", "beamLightning", "beamHoly", "beamArcane",
	"beamPoison", "trailSoft", "trailStreak", "iceShard", "poisonBubble", "feather", "darkSpark" }

-- Rune circle of a class (Classes ids), magicCircle for anything else.
local RUNE_OF_CLASS = { Warrior = "runeWarrior", Hunter = "runeHunter", Mage = "runeMage", Cleric = "runeCleric" }

return table.freeze({
	list = table.freeze(list),
	ORDER = table.freeze(ORDER),
	RUNE_OF_CLASS = table.freeze(RUNE_OF_CLASS),
	get = function(key: string): Texture? return list[key] end,
	-- The uploaded id, nil while empty (callers fall back to the old look).
	idOf = function(key: string): string?
		local t = list[key]
		return if t and t.id ~= "" then t.id else nil
	end,
})
```
(Ostateczne formatowanie zrobi StyLua; każdy wpis zamrożony jak w `Data/Families`.)

**C2. `src/client/Vfx/Textures.luau` (nowy, klient):** jedyne miejsce, które zamienia dane na `Enum` i właściwości.
- `Textures.enabled: boolean` (domyślnie `Config.Vfx.textures`; `/animlab vfx tex off|on` przełącza do porównań „przed/po”, E7).
- `Textures.id(key: string): string?`: `nil`, gdy wyłączone, gdy `VfxTextures.idOf(key)` jest `nil` albo gdy `Pool` rysuje do podglądu w `ViewportFrame` (`Pool.inViewport()`, C3).
- `Textures.particle(e: ParticleEmitter, key: string): boolean`: ustawia `Texture`, `LightEmission` (z danych, jeśli wywołujący nie podał), `LightInfluence = 0` dla `emission > 0`, a dla flipbooka `FlipbookLayout` (`"4x4"` → `Enum.ParticleFlipbookLayout.Grid4x4` itd.), `FlipbookMode` (`"oneShot"` → `Enum.ParticleFlipbookMode.OneShot`), `FlipbookFramerate` = `NumberRange.new(frames / lifetimeMax)` dla `OneShot` (cała sekwencja w życiu cząsteczki), 16–24 kl./s dla `Loop`. Zwraca `false` (bez zmian w emiterze), gdy `Textures.id` daje `nil`.
- `Textures.beam(b: Beam, key: string, opts: { speed: number?, length: number? }?): boolean`: `Texture`, `TextureMode = Wrap` dla `wrap`, inaczej `Stretch`, `TextureLength` (domyślnie 4 st.), `TextureSpeed` (domyślnie 0), `LightEmission = 1`, `LightInfluence = 0`.
- `Textures.trail(t: Trail, key: string): boolean`: `Texture`, `TextureMode = Stretch`, `LightInfluence = 0`.
- `Textures.decal(d: Decal, key: string): boolean`: `Texture`.
- `Textures.check(): { [string]: string }`: dla `/animlab vfx tex` (E7) w Play tworzy `ImageLabel` w ukrytym `ScreenGui` dla każdego niepustego ID i po 10 s zwraca `key → "ok" | "not loaded"` (wzór uwagi z `docs/ASSETS.md`; nie `PreloadAsync` na tekście) i dla flipbooków emiter próbny z odczytem `FlipbookIncompatible` (pusty tekst = dobrze).

**C3. Pula „uchwytów” (`Vfx/Pool.luau`).** `Pool.release` niszczy dzieci części, więc emiter z teksturą, `Beam` i `Decal` powstawałyby przy każdym efekcie. Dodaj osobne uchwyty, które zachowują swoje dziecko:
```lua
export type HolderKind = "emitter" | "beam" | "decal"
-- An invisible anchored part (Transparency 1, no collisions / queries) with one prepared child: "VfxEmitter"
-- (ParticleEmitter, Rate 0, Enabled true), "VfxBeam" (Beam between attachments "A0" and "A1") or "VfxDecal"
-- (Decal on Top). The texture of `key` is applied once, when the holder is created; nil when the device limit
-- of the kind (C4) is reached, so the caller skips that optional layer.
function Pool.holder(kind: HolderKind, key: string): BasePart?
-- Back to the pool: emitter:Clear(), beam / decal Transparency 1, attachments and properties reset; the child stays.
-- At most Config.Vfx.holdersPerKey free holders per kind and key, the rest are destroyed.
function Pool.releaseHolder(p: BasePart)
function Pool.holderLater(p: BasePart, seconds: number)
function Pool.holderCount(kind: HolderKind): number -- holders in use (limits, /animlab vfx stats)
function Pool.inViewport(): boolean -- true while setOverride points into a preview WorldModel
function Pool.isTouch(): boolean -- TouchEnabled and not KeyboardEnabled (same rule as AnimationController)
function Pool.limit(name: "emitters" | "beams" | "decals" | "lights"): number -- Config.Vfx.max<Name> for the device
```
Uchwyty mają atrybut `VfxHolder = "<kind>:<key>"`; `Pool.release` na uchwycie przekazuje do `releaseHolder` (żeby stary kod nie zniszczył dziecka przez pomyłkę). Emiter uchwytu ma osobne właściwości ustawiane przy każdym użyciu (kolor, rozmiar, prędkość) przez helper `Library` (D2). Światła: nowe składniki biorą `PointLight` przez licznik `Pool.lights` (inkrementacja przy utworzeniu, dekrementacja przy zwrocie), nie więcej niż `Pool.limit("lights")`.

### E. Nowe składniki

Wspólny typ opcji w `Library`:
```lua
export type FxOpts = {
	simple: boolean?, -- far away or low quality (C5)
	key: string?, -- texture key override (Data/VfxTextures)
	dir: Vector3?, -- main direction (sparks: away from the blow)
	count: number?, -- particles (before C5)
	seconds: number?,
	spin: number?, -- rad/s (circles)
	yaw: number?, -- fixed rotation in radians (decals); random when nil
}
```

**E1. `Library.impactFlash(at: Vector3, size: number, color: Color3, opts: FxOpts?)`** — rdzeń trafienia (§2.6, 0,05–0,1 s). Z teksturą: uchwyt emitera `star`: 1 cząsteczka, `Lifetime` 0,08, `Size` `NumberSequence { 0: size·0,6, 1: size·1,15 }`, `Transparency { 0: 0, 0.6: 0.2, 1: 1 }`, losowa `Rotation`, `ZOffset = 1`, `LightEmission = 1`; do tego 1 cząsteczka `glow` (`size·1,6`, 0,12 s, przezroczystość 0,35 → 1); `PointLight` (`Range = size·3`, `Brightness = 3`) na 0,1 s, gdy nie `simple` i jest miejsce w `maxLights`. Bez tekstury: neonowa kula 0,3 → `size`, 0,08 s (jak `burst`, krócej).

**E2. `Library.sparks(at: Vector3, color: Color3, opts: FxOpts?)`** — ślad (iskry, odłamki). Klucz domyślny `spark` (S113 poda `darkSpark`, `iceShard`, `feather`, `dust` według materiału). Uchwyt emitera ustawiony `CFrame.lookAt(at, at + dir)`, `EmissionDirection = Front`, `SpreadAngle = (35, 35)`, `Speed` 10–22, `Acceleration = (0, −40, 0)`, `Drag = 3`, `Lifetime` 0,18–0,4, `Orientation = VelocityParallel` dla `spark` (dla reszty `FacingCamera`), `Size` 0,15–0,28, liczba domyślnie 8 (C5). Bez `dir`: w górę. Bez tekstury: ten sam emiter bez `Texture` (domyślna cząsteczka, dzisiejszy styl).

**E3. `Library.groundDecal(at: Vector3, radius: number, key: string, color: Color3, seconds: number, opts: FxOpts?): () -> ()`** — ciemne ślady na ziemi (`cracks`, później S117: osmalenie, pęknięcia telegrafu). Uchwyt `decal`: część `(radius·2, 0.05, radius·2)` na `ground(at) + 0.06`, obrót `opts.yaw` albo losowy, `Decal.Face = Top`, `Color3 = color` (dla pęknięć ciemny: wywołujący poda), przezroczystość 1 → 0,1 w 0,06 s, trzyma, w ostatnich `Config.Vfx.decalFade` s → 1. Zwraca funkcję, która zdejmuje ślad od razu (telegrafy S117). Limit `maxDecals`: ponad limit najstarszy ślad gaśnie natychmiast (lista FIFO), nowy się pojawia. Bez tekstury: `Library.cracks` z części (dla `cracks`), dla innych kluczy nic (to nowa warstwa, nie zastępstwo).

**E4. `Library.smokePuff(at: Vector3, size: number, color: Color3, opts: FxOpts?)`** — ślad (dym, pył). Uchwyt emitera `smoke` (flipbook 4×4 `OneShot`): liczba 3–5 (C5), `Lifetime` 0,9–1,3, `FlipbookFramerate = 16 / 1.3` (cała sekwencja), `Speed` 1–3, `SpreadAngle (60, 60)`, `Acceleration (0, 1.5, 0)`, `RotSpeed` −30…30, `Rotation` losowa, `Size { 0: 0.6·size, 1: 2.2·size }`, `Transparency { 0: 0.3, 1: 1 }`, `LightEmission = 0`, `LightInfluence = 1` (dym oświetlony sceną). Bez tekstury: `Library.dust(at, size, simple)`.

**E5. `Library.magicCircle(at: Vector3, radius: number, color: Color3, seconds: number, opts: FxOpts?): () -> ()`** — ciało efektów magii i leczenia, później telegrafy magii (S117). Uchwyt `beam`: płaska Beam leżąca na ziemi: `A0` i `A1` w odległości `radius` od środka po osi X uchwytu, `Width0 = Width1 = radius·2`, `FaceCamera = false`, `Segments = 1`, `LightEmission = 1`, `LightInfluence = 0`, `Transparency` 1 → 0,15 w 0,15 s; orientację attachmentów (`Axis`/`SecondaryAxis`) dobierz tak, żeby płaszczyzna Beam była pozioma (sprawdź zrzutem z `AnimLabCam_Top` i `_Side`: z boku ma być kreska). Klucz: `opts.key` albo `magicCircle`. Obrót: wspólna pętla `spinning` w `Library` (jedno połączenie `Heartbeat` dla wszystkich kół, nie jedno na koło) obraca `CFrame` uchwytu o `opts.spin` (domyślnie `Config.Vfx.spinStep`). Po `seconds` gaśnie w `decalFade`. Zwraca funkcję zatrzymania. Bez tekstury: `Library.rune(at, radius, color, seconds, simple)` (zatrzymanie: brak, bo dziś `rune` sam gaśnie; zwróć funkcję pustą).

**E6. `Library.ringWave(at: Vector3, radius: number, color: Color3, opts: FxOpts?)`** — ciało fali uderzeniowej. Płaska Beam jak w E5 z kluczem `ring`; tween `Width0/1` i pozycji `A0`/`A1` od `0,3·radius` do `2·radius` w `opts.seconds` (domyślnie 0,4 s, `Quad Out`), przezroczystość 0,1 → 1. Bez tekstury: `Library.shockwave(at, radius, color, 0.45, true)` (wersja prosta).
