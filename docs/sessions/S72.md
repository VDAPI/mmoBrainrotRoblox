2. **`src/shared/Logic/Fury.luau`** (nowy, czysty, ok. 80 linii, bez `require` danych: reguły przychodzą argumentem):
   ```lua
   --!strict
   -- Fury of the Berserker (ROZWOJ 10.4): pure stack rules. The server keeps one State per player
   -- (StatusEffectService) and passes Data/Paths HOOK_RULES.fury as the rules; times are os.clock() seconds. Every function
   -- returns a new table and never changes its input.
   export type Rules = { gainInterval: number, decayAfter: number, decayPerSecond: number }
   export type State = {
   	stacks: number,
   	base: number, -- stacks when the decay clock last restarted (a hit, Carnage, set)
   	quietSince: number, -- the last hit (or Carnage step, or set): decay starts decayAfter seconds later
   	lastGain: number, -- when a stack was last gained (gainInterval throttle); -math.huge = never
   }
   function Fury.new(): State
   -- A hit that dealt damage: +amount (1; Carnage: HOOK_RULES.carnage.furyGain) up to max, at most one gain per
   -- gainInterval. The decay clock restarts even when nothing was gained (at max or throttled).
   function Fury.gain(state: State, now: number, max: number, amount: number, rules: Rules): State
   -- Time passing. Out of combat or with max <= 0: a new (empty) state. Carnage (`frozen`) holds the stacks and
   -- restarts the decay clock. Otherwise, decayAfter seconds after quietSince the stacks fall from `base` by
   -- decayPerSecond per second (one stack every 0.5 s with the default rules).
   function Fury.step(state: State, now: number, max: number, inCombat: boolean, frozen: boolean, rules: Rules): State
   -- Spends every stack (furyConsume, S73): the new state and how many were spent.
   function Fury.consume(state: State): (State, number)
   -- Sets the stacks (furyRestore, S75), clamped to 0..max; the decay clock restarts at `now`.
   function Fury.set(state: State, now: number, stacks: number, max: number): State
   ```
   Reguły dokładnie:
   - `new()` = `{ stacks = 0, base = 0, quietSince = 0, lastGain = -math.huge }`.
   - `gain`: przy `max <= 0` zwraca stan z `stacks = 0`, `base = 0`, `quietSince = now`. Inaczej `s = min(state.stacks, max)`; gdy `s < max` i `now − state.lastGain >= rules.gainInterval`: `s = min(max, s + amount)`, `lastGain = now`; zawsze `base = s`, `quietSince = now`.
   - `step`: gdy `not inCombat` albo `max <= 0` → `new()`. `s = min(stacks, max)`, `b = min(base, max)`. Gdy `frozen` → `{ stacks = s, base = s, quietSince = now, lastGain }`. Inaczej `elapsed = now − quietSince − rules.decayAfter`; przy `elapsed <= 0` stan z `s` i `b` bez zmian zegara; przy `elapsed > 0`: `stacks = max(0, min(s, b − floor(elapsed × rules.decayPerSecond + 1e-9)))`.
   - `consume`: `{ stacks = 0, base = 0, quietSince = state.quietSince, lastGain = state.lastGain }` i `state.stacks`.
   - `set`: `s = clamp(floor(stacks), 0, max(0, max))`, `{ stacks = s, base = s, quietSince = now, lastGain = state.lastGain }`.

### F. Przechwyt: Męczennik i Kara (`Logic/Intercept`, filtr S61)

1. **`src/shared/Logic/Intercept.luau`** (z S61) dostaje:
   ```lua
   -- The part a guard really takes and the damage sent back to the monster that struck (ROZWOJ 10.3). Martyr
   -- (`mitigation` %, interceptMitigation) lowers the guard's part; Retribution (`thorns` %, interceptThorns) returns a
   -- share of the moved part, at least 1 while it is on. Both read the part before mitigation, and the per-second
   -- window (take) counts that part too.
   function Intercept.split(moved: number, mitigation: number, thorns: number): (number, number)
   ```
   `moved <= 0` → `0, 0`; `toGuard = moved × (1 − clamp(mitigation, 0, 100) / 100)`; `reflected = if thorns > 0 then max(1, floor(moved × thorns / 100)) else 0`.
2. **Filtr przechwytu** (lokalny `interceptFilter` z S61 w `StatusEffectService`). Tam, gdzie po `Intercept.resolve` przy `moved > 0` S61 woła `ResourceService.Damage(guard, moved, "intercept", attacker)`:
   ```lua
   local guard = chosen.guard :: Player
   local toGuard, reflected =
   	Intercept.split(moved, hookOf(guard, "interceptMitigation"), hookOf(guard, "interceptThorns"))
   local taken = 0
   if toGuard > 0 then
   	local _, filtered = ResourceService.Damage(guard, toGuard, "intercept", attacker)
   	taken = filtered
   end
   -- Retribution: back to the monster that struck (the attacker argument from S61); straight to its HP like thorns.
   local returned = 0
   if reflected > 0 and type(attacker) == "table" and attacker.IsAlive and attacker:IsAlive() then
   	returned = attacker:TakeDamage(reflected, guard)
   end
   StatusEffectService.Intercepted:Fire(guard, player, moved, taken, attacker, returned)
   ```
   Okno sekundowe (`windows`) i „przejęte obrażenia” w podsumowaniu walki (S61) dalej liczą `moved`, czyli część przed Męczennikiem. Reszta ciosu (`kept`) wraca do filtrów celu jak dziś.
