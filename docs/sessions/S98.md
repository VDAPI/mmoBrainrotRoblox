### C. Budżet EXP i kompensacja (DESIGN-15 §3.2)

Zasada: czas na poziom w modelu tempa jest równy czasowi z S94. Questy zastępują bicie: gdy questy dają na poziomie L więcej EXP niż w stanie bazowym, potwory dają na tym poziomie proporcjonalnie mniej, tak że **godziny bicia** zostają takie same. Liczy się to z prostego, sprawdzalnego wzoru na „udziale bicia”:

- `E(L) = Exp.expToNext(L)`, `Q(L)` = EXP questów zaliczony poziomowi L w modelu (z przeniesieniem nadmiaru, jak w `paceWindowAt`), `K(L) = max(0, E(L) − Q(L) − carryIn(L))` = EXP do wybicia z potworów, `s(L) = K(L) / E(L)` = udział bicia;
- `s₀(L)` = udział bicia stanu bazowego (zamrożony w `tests/fixtures/quest_budget_base.json`, C4);
- `monsterExpMul(L) = s(L) / s₀(L)` (1, gdy `s₀(L) = 0` albo `s(L) = 0`), przycięte do `[MUL_MIN, MUL_MAX]` i zaokrąglone do 0,001.

Skoro godziny bicia w modelu to `K / (EXP za zabicie × mul) × sekundy na zabicie` (z odpoczynkiem proporcjonalnym do zabić), `K/mul` = `s₀ × E`, czyli dokładnie bazowy czas przy dzisiejszej krzywej `expToNext`. Przechowujemy udziały, nie EXP, więc późniejsza zmiana krzywej (np. audyt S109) nie psuje odniesienia.

-- Quest EXP budget (S98, docs/DESIGN-15.md §3.2). Quests replace part of the grinding: TARGET is the share of a
-- level's EXP that one-time quests give a player who does the contract, the story and the side quests (daily and
-- weekly contracts are outside the budget). MONSTER_EXP_MUL compensates: monster EXP at character level L is
-- multiplied by it so that the hours of grinding per level stay those of S94. The table between the GENERATED markers
-- is written by `lune run tools/quest_budget.luau` from the real quest data; never edit it by hand.
-- tests/questbudget.spec.luau fails when it is out of date.
return table.freeze({

	BANDS = table.freeze({ { 1, 19 }, { 20, 44 }, { 45, 69 }, { 70, 99 } }), -- budget bands (levels that need EXP)
	MUL_MIN = 0.5,
	MUL_MAX = 1.25,
	-- BEGIN GENERATED (lune run tools/quest_budget.luau)
	MONSTER_EXP_MUL = table.freeze({ … 99 numbers, index = character level … }),
	-- END GENERATED
})

`Logic/QuestBudget`:
- `monsterExpMul(level): number` = `MONSTER_EXP_MUL[clamp(floor(level), 1, 99)]` albo 1 (poziom 100 nie zbiera EXP);

- `bandExp(level): number` = Σ `Exp.expToNext(L)` po paśmie poziomu;
- `bossQuestExp(level, count): number` = `floor(bandExp(level) × TARGET.boss / max(count, 1))` (A3);
- `shares(credit): { [string]: number }` (pomocnik raportu: udział EXP kategorii w paśmie z wyniku rozbitego na kategorie; jeśli prościej, trzymaj to w narzędziu, nie w `Logic`).
